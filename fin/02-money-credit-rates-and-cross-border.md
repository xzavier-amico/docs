## 02.1 引子：一条报文能搬走 1 亿美元，一份「安全资产」能吞掉全部权益

### 案例一：2016 年孟加拉国央行 SWIFT 失窃案

2016 年 2 月，攻击者在入侵孟加拉国央行内部网络后，伪造了 35 笔经 SWIFT 发往纽约联储的付款指令，指令总额约 9.51 亿美元，收款方分布在菲律宾与斯里兰卡等地。其中 5 笔得以执行，合计约 1.01 亿美元：约 8,100 万美元流入菲律宾的账户，约 2,000 万美元流向斯里兰卡（后因收款人名称拼写异常被拦截）。其余 30 笔约 8.5 亿美元因纽约联储的人工复核与报文要素疑点而被暂停。

这起事件的关键不在「黑客技术」，而在资金到底是怎样移动的。SWIFT 报文本身没有任何一分钱，真正被扣减的是孟加拉国央行在纽约联储开立的美元账户：

```text
【纽约联储账簿：一笔被伪造的付款指令生效后】

  纽约联储（Fed）资产负债表（只画受影响的负债科目）
  +--------------------------------+--------------------------------+
  | 资产（无变化）                 | 负债                           |
  |                                | 孟加拉国央行美元账户   - 1.01 亿 |
  |                                | 收款行代理账户         + 1.01 亿 |
  +--------------------------------+--------------------------------+

  报文层（SWIFT）：  "请从本行账户划付 USD ××× 给 ×××"   ← 只是授权文本
  账簿层（Fed）：    借 孟加拉国央行账户 / 贷 收款行代理账户 ← 资金真正移动处
  结论：报文通过认证 = 账户持有人的授权被视为有效；认证被攻破，账户就被合法地扣减
```

教训有三条：第一，付款授权的真实性由报文终端的密钥与操作员控制，而不是由 SWIFT 网络保证；第二，一旦在 RTGS 系统里记账，该笔款项即具有终局性（Finality），事后追回只能靠对手方自愿退回或司法冻结；第三，收款行侧的人工复核与名称校验，是最后一道也是最薄的防线。

### 案例二：2023 年 3 月硅谷银行（SVB）——利率曲线与久期错配

硅谷银行在 2022 年末的数据量级大致为：存款约 1,730 亿美元，股东权益约 163 亿美元，持有至到期（HTM）证券账面约 913 亿美元，其中未实现损失约 151 亿美元。这些证券多为长久期的美国国债与政府支持机构抵押债券，在利率快速上行的 2022 年大幅贬值，而会计上因 HTM 分类不计入当期损益。

2023 年 3 月 9 日，客户单日提款申请约 420 亿美元。银行要兑付这笔存款，必须卖出证券，浮亏随之「实现」，约 151 亿美元的亏损几乎吞噬约 163 亿美元的全部权益。其账表示意如下（数字为取整的教学化示意，非监管报表原值）：

```text
【SVB 式资产负债表（量级示意，单位：亿美元）】

  资产                              负债与权益
  现金与准备金           ~  138     客户存款              ~ 1,730
  可供出售证券(AFS)      ~  266     借款及其他负债        ~   224
  HTM 长久期证券(账面)   ~  913     股东权益              ~   163
  贷款                   ~  740     （其中 HTM 浮亏       ~  -151 未入账）
  其他资产               ~   60
  合计                   ~ 2,117     合计                  ~ 2,117
  校验：138 + 266 + 913 + 740 + 60 = 2,117；1,730 + 224 + 163 = 2,117
  重点：浮亏 151 对比权益 163，缓冲仅剩 12 左右

  挤兑冲击：单日提款 420 → 现金 138 不足 → 被迫卖证券 → 浮亏转为已实现亏损 → 权益被击穿
```

「无风险利率」与「无信用风险」不等于「无价格风险」。国债不会违约，但它的现值会随收益率曲线重定价而下跌，下跌幅度由久期决定。本章 02.4 会以三年期债券手工算出：曲线平移 100 个基点，价格下跌约 2.81 元（面值 100）。

## 02.2 唯一真问题与反直觉定义

### 唯一真问题

> **在一个由账簿组成的世界里，「钱」是谁的负债、由谁创造、以什么价格借出，以及当债权债务跨越货币与司法边界时，最终是在哪一本账簿上完成了终局性的借贷记账？**

围绕这个问题，本章的四条精确定义如下：

1. **基础货币（Monetary Base，M0 的广义口径）**：央行的负债，包括公众持有的现金与商业银行存放在央行的准备金。只有它具备最终结算（Final Settlement）能力。
2. **存款货币（Inside Money）**：商业银行的负债。银行发放贷款时，同时在借款人账户记入一笔新存款，信贷创造存款，存款是银行对客户的债务，而非准备金的「仓库凭证」。
3. **利率**：跨期资金的价格，等于对「今天的 1 元」与「未来的 1 元」做交换时的折价比率；无风险利率是以主权本币债务为锚的最低参照，而不是「零风险」。
4. **清算（Clearing）与结算（Settlement）**：清算是交易指令的确认、对比与轧差；结算是在最终账簿上完成资产与资金的实际划转。SWIFT 属于报文通道，不属于结算系统。

### 常见误区对照表

| 常见误区 | 为什么错 | 真实代价 |
| --- | --- | --- |
| 银行先吸收存款，再把存款借出去 | 贷款发放瞬间即创造存款；准备金约束体现在事后的跨行清算与流动性管理上，而不是放贷之前 | 把存款当作「可贷资金池」设计额度模型，会严重误判银行扩张的真实约束（资本与流动性） |
| 货币乘数等于 1 除以法定准备金率 | 乘数还受现金漏损率、超额准备金率、借款需求影响；美国在 2020 年 3 月把法定准备金率降至 0，乘数公式失去约束意义 | 用理想乘数推算货币供应，偏差可达数倍 |
| 国债是无风险资产，持有到期就不会亏 | 无违约风险不等于无价格风险与流动性风险；负债端被挤兑时，被迫出售即实现亏损 | SVB 式的久期错配，权益被浮亏吞噬 |
| 收益率曲线倒挂必然导致衰退 | 倒挂反映的是市场对未来短端利率下行的预期，是统计上的先行信号，不是因果机制 | 机械地以倒挂做择时，会在长达数个季度的倒挂期内踏空或误判 |
| SWIFT 是跨境转账系统，钱经过 SWIFT 到账 | SWIFT 只传输标准化报文，不持有账户也不记账；资金通过 RTGS 系统或代理行往来户移动 | 报文已发出等同于资金已到账的错误假设，导致状态机提前确认 |
| 汇率可以同时固定、资本自由流动、利率独立 | 蒙代尔不可能三角：三者最多同时满足其二 | 1992 年英镑退出欧洲汇率机制、2015 年瑞郎脱钩事件，均为强行三者兼得后被市场清算 |
| 卡组织（Visa/Mastercard）是收款的「钱包」 | 卡组织不持有持卡人资金，它定义规则、路由授权、提供清算与结算指令，并收取网络费 | 对商户手续费构成认知错误，导致分账与对账口径偏差 |
| 手续费 2.5% 就是银行赚 2.5% | 商户折扣率（MDR）由交换费、卡组费、收单行加价三层组成，发卡行拿大头 | 把收单行成本当成全链路成本，定价与分润模型失真 |

## 02.4 核心定价与手工算账推演

以下所有算式均以「万元」或「元」为单位，并给出可复算的每一步。

### 4.1 T 型账表连续推演：从基础货币到信贷派生存款

**设定（教学推演案例）**：法定准备金率 r = 10%；央行向银行 A 注入基础货币 1,000 万元；暂不考虑现金漏损与超额准备金；所有贷款款项均被收款人存回银行体系。

**第 0 步：央行购入国债，注入基础货币 1,000**

```text
央行                                  银行 A
资产            | 负债                资产              | 负债
国债    +1,000  | A 准备金 +1,000     国债     -1,000   | （无变化）
                |                     准备金   +1,000   |
合计    +1,000  | 合计    +1,000      合计        0     | 合计      0
```

此时基础货币增加 1,000，银行体系尚未创造任何新存款，银行 A 只是资产结构变化（国债换准备金）。

**第 1 步：客户 C1 把 1,000 现金存入银行 A（等价的另一种起点：公众持有的现金回流银行）**

```text
银行 A
资产                    | 负债
准备金         1,000    | 客户 C1 存款       1,000
合计           1,000    | 合计               1,000
法定准备金 = 1,000 × 10% = 100；可放贷额 = 1,000 - 100 = 900
```

**第 2 步：银行 A 向借款人 L1 发放 900 万元贷款**

放款瞬间，银行在 L1 的账户贷记一笔新存款，资产负债表同时扩张：

```text
银行 A（放款瞬间）
资产                    | 负债
准备金           1,000  | C1 存款             1,000
贷款（对 L1）      900  | L1 存款               900
合计             1,900  | 合计                1,900
```

此刻存款总量从 1,000 变为 1,900，货币已被创造，而准备金仍是 1,000，没有减少。**约束出现在下一步：L1 把 900 付给在银行 B 开户的供应商 S1。**

**第 3 步：L1 付款给银行 B 的客户 S1，跨行清算 900**

```text
银行 A（清算后）                         银行 B（清算后）
资产              | 负债                 资产              | 负债
准备金      100   | C1 存款     1,000    准备金       900  | S1 存款         900
贷款        900   | L1 存款        0     合计         900  | 合计            900
合计      1,000   | 合计       1,000
```

银行 A 的准备金恰好等于法定要求 100（= 1,000 × 10%），不能再无风险放贷；银行 B 获得 900 准备金，可放贷 900 - 90 = 810。这一步展示了准备金约束发生在跨行清算时：A 必须有足够的准备金（或从同业拆入）才能完成 900 的付款。

**第 4 步及以后：逐轮递减，几何级数收敛**

每一轮新增存款为上一轮的 90%（1 - r）：

| 轮次 n | 本轮新增存款（万元） | 累计存款（万元） | 本轮留存准备金（万元） | 本轮新增贷款（万元） |
| --- | --- | --- | --- | --- |
| 1 | 1,000.00 | 1,000.00 | 100.00 | 900.00 |
| 2 | 900.00 | 1,900.00 | 90.00 | 810.00 |
| 3 | 810.00 | 2,710.00 | 81.00 | 729.00 |
| 4 | 729.00 | 3,439.00 | 72.90 | 656.10 |
| 5 | 656.10 | 4,095.10 | 65.61 | 590.49 |
| …… | …… | …… | …… | …… |
| 10（累计） | — | 6,513.22 | — | — |
| ∞（极限） | — | 10,000.00 | 1,000.00 | 9,000.00 |

累计公式：D(n) = 1,000 × (1 - 0.9ⁿ) / 0.1。取 n = 5：0.9⁵ = 0.59049，D = 1,000 × 0.40951 / 0.1 = 4,095.10；取 n = 10：0.9¹⁰ = 0.3486784401，D = 1,000 × 0.6513215599 / 0.1 = 6,513.215599，约 6,513.22。极限值 D = 1,000 / 0.1 = 10,000。

**终态合并资产负债表（整个银行体系）**：

```text
银行体系终态（单位：万元）
资产                       | 负债
准备金           1,000     | 存款合计        10,000
贷款             9,000     |
合计            10,000     | 合计            10,000

校验：准备金 / 存款 = 1,000 / 10,000 = 10% = r ✓
      贷款 = 存款 - 准备金 = 10,000 - 1,000 = 9,000 ✓
      借贷平衡：10,000 = 10,000 ✓
```

**理想货币乘数 m₀ = 1 / r = 1 / 0.10 = 10**。

### 4.1.2 货币乘数的真实边界：加入现金漏损与超额准备金

设现金漏损率 c = 20%（公众把存款的 20% 以现金形式持有），法定准备金率 r = 10%，超额准备金率 e = 5%，基础货币 B = 1,000。

1. 基础货币 B = 公众现金 C + 银行准备金 R；
2. C = c × D，R = (r + e) × D；于是 B = (c + r + e) × D；
3. 货币供应 M1 口径近似 M = C + D = (1 + c) × D；
4. 乘数 m = M / B = (1 + c) / (c + r + e)。

数值推演：

| 情形 | 参数 | D（存款） | C（现金） | M = C + D | 乘数 m |
| --- | --- | --- | --- | --- | --- |
| 理想 | c = 0, e = 0, r = 10% | 10,000.00 | 0.00 | 10,000.00 | 10.0000 |
| 加漏损 | c = 20%, e = 0, r = 10% | 1,000 / 0.30 = 3,333.33 | 666.67 | 4,000.00 | 1.2 / 0.30 = 4.0000 |
| 再加超额 | c = 20%, e = 5%, r = 10% | 1,000 / 0.35 = 2,857.14 | 571.43 | 3,428.57 | 1.2 / 0.35 = 3.4286 |

校验再加超额情形：准备金 R = 0.15 × 2,857.14 = 428.57；现金 C = 571.43；R + C = 1,000.00 = B ✓。乘数从理想的 10 跌到 3.43，说明「1/r」只是上限；当银行风险偏好下降、超额准备金堆积（e 上升）或公众偏好现金（c 上升），乘数会继续收缩。

**资本约束：真正决定放贷上限的往往是资本**。若银行 A 的核心一级资本为 80 万元，监管要求资本充足率 8%，贷款风险权重 100%，则风险加权资产上限 = 80 / 0.08 = 1,000 万元，即便准备金充裕，A 的贷款余额也不能超过 1,000 万元。这就是「贷款创造存款，资本约束扩张」的定量含义。

### 4.2 无风险利率、收益率曲线与 DCF 精确算账

**定义**：现金流 CFₜ 在第 t 年到期，以即期利率 sₜ（年复利）贴现，则 PV = Σ CFₜ / (1 + sₜ)ᵗ。

**设定（教学推演案例）**：国债即期收益率曲线（年复利，零息口径）：

| 期限 | 1 年 | 2 年 | 3 年 |
| --- | --- | --- | --- |
| 即期利率 s | 2.00% | 2.40% | 2.70% |

**(a) 三年期、票息 3%、面值 100 的年付息国债定价**：现金流为第 1 年 3、第 2 年 3、第 3 年 103。

- 第 1 年：3 / 1.02 = 2.941176…，取 2.9412
- 第 2 年：1.024² = 1.048576；3 / 1.048576 = 2.861023…，取 2.8610
- 第 3 年：1.027² = 1.054729；1.054729 × 1.027 = 1.083206683；103 / 1.083206683 = 95.088040…，取 95.0880
- 价格 P = 2.9412 + 2.8610 + 95.0880 = **100.8902**（保留四位小数的精确值 100.890239…）

票息 3% 高于曲线对应利率，价格高于面值，符合「溢价债券」的预期。到期收益率 YTM 是使同一组现金流贴现为 100.8902 的单一利率，数值求解得 YTM ≈ 2.687%，处于 2.00% 至 2.70% 之间，更靠近长端（因为大部分现金流在第 3 年）。

**(b) 隐含远期利率**：远期利率 f(t₁,t₂) 满足 (1 + s₂)² = (1 + s₁) × (1 + f(1,2))。

- f(1,2) = 1.048576 / 1.02 - 1 = 1.028016 - 1 = **2.8016%**
- f(2,3) = 1.083206683 / 1.048576 - 1 = 1.033026 - 1 = **3.3026%**

正常（向上倾斜）曲线下，远期利率逐段上升（2.00% → 2.80% → 3.30%），反映期限溢价与对未来利率上行的预期。

**(c) 曲线倒挂**：假设即期利率变为 1 年 4.50%、2 年 4.20%、3 年 3.90%。

- f(1,2) = 1.042² / 1.045 - 1 = 1.085764 / 1.045 - 1 = **3.9009%**
- f(2,3) = 1.039³ / 1.042² - 1：1.039² = 1.079521，1.079521 × 1.039 = 1.121622319；1.121622319 / 1.085764 = 1.033026，即 **3.3026%**
- 同一只 3% 票息国债的价格 = 3 / 1.045 + 3 / 1.085764 + 103 / 1.121622319 = 2.8708 + 2.7630 + 91.8313 = **97.4651**，低于面值。

倒挂的经济含义：市场对未来短端利率的预期低于当前（隐含远期利率逐段下降），典型成因包括：央行为抑制通胀把政策利率推高、市场预期随后经济放缓导致降息；长端受避险买盘压低。对银行体系而言，倒挂意味着「短借长贷」的息差收窄甚至为负，存贷利差与久期错配的压力同步上升。

**(d) 利率冲击：曲线平移 +100 个基点**（1 个基点 = 0.01%）：即期利率变为 3.00%、3.40%、3.70%。

- 第 1 年：3 / 1.03 = 2.9126
- 第 2 年：1.034² = 1.069156；3 / 1.069156 = 2.8060
- 第 3 年：1.037³ = 1.115157…（1.037² = 1.075369；× 1.037 = 1.115157653）；103 / 1.115157653 = 92.3636
- 价格 = 2.9126 + 2.8060 + 92.3636 = **98.0822**
- 价格变动 = 98.0822 - 100.8902 = **-2.8080**，跌幅 2.78%。

这就是 SVB 案例中「无违约但有浮亏」的算式原型：久期约 2.8 年的债券，利率上行 100 个基点，价格约下降 2.8%；如果组合久期为 6 年，浮亏接近 6%，再乘以千亿级持仓，足以吞噬百亿级权益。

**(e) 名义利率与实际利率（费雪关系）**：名义利率 3%，通胀 2%，精确实际利率 = 1.03 / 1.02 - 1 = **0.9804%**，近似公式 3% - 2% = 1% 有约 2 个基点的误差。

**(f) 企业项目 DCF（教学推演案例）**：初始投资 1,000（第 0 年流出），之后各年净现金流 300、400、500、200，贴现率 8%。

| 年份 t | 现金流 | 贴现因子 1 / 1.08ᵗ | 现值 |
| --- | --- | --- | --- |
| 0 | -1,000 | 1.000000 | -1,000.00 |
| 1 | 300 | 0.925926 | 277.78 |
| 2 | 400 | 0.857339 | 342.94 |
| 3 | 500 | 0.793832 | 396.92 |
| 4 | 200 | 0.735030 | 147.01 |
| 合计 NPV | | | **164.64** |

敏感性：贴现率升到 9%，NPV 降至 139.68；降到 6%，NPV 升至 217.25。贴现率每上升 1 个百分点，NPV 减少约 25，说明估值对无风险利率与风险溢价高度敏感，也是利率周期决定估值周期的根本原因。

### 4.3 蒙代尔不可能三角与抛补利率平价

**不可能三角**：一国无法同时实现（1）固定汇率；（2）资本自由流动；（3）独立的货币政策。任何时刻只能取其二。

| 组合 | 放弃 | 典型例子 | 机制 |
| --- | --- | --- | --- |
| 固定汇率 + 资本自由流动 | 独立货币政策 | 香港联系汇率制（港元兑美元约 7.75～7.85 区间） | 利率被迫跟随美元利率，套利资金自动调节货币基础 |
| 固定汇率 + 独立货币政策 | 资本自由流动 | 资本管制型盯住汇率 | 以资本管制切断套利通道 |
| 独立货币政策 + 资本自由流动 | 固定汇率 | 美元、欧元、日元等浮动汇率 | 汇率承担外部冲击的缓冲 |

**抛补利率平价（CIP）**：远期汇率 F = S × (1 + i本币) / (1 + i外币)（汇率以每 1 外币兑本币标价）。

**设定（教学推演案例）**：USD/CNY 即期 S = 7.2000；1 年期 CNY 利率 2.00%，USD 利率 5.00%。

- 平价远期 F = 7.2000 × 1.02 / 1.05 = 7.344 / 1.05 = **6.994286**。
- 远期点 = 6.994286 - 7.2000 = -0.205714，即约 -2,057 点（以 0.0001 为 1 点）。美元利率更高，美元远期贴水，人民币远期升水。

**无套利验证**：期初持有 1,000,000 美元。

- 路径 A：投资美元 1 年 → 1,000,000 × 1.05 = 1,050,000 美元；
- 路径 B：按 7.2000 换为 7,200,000 人民币，投资 1 年 → 7,200,000 × 1.02 = 7,344,000 人民币；按平价远期卖出换回美元 = 7,344,000 / 6.994286 = 1,050,000 美元，两条路径相等 ✓。

若市场报价远期 F = 7.1000（高于平价）：借入 7,200,000 人民币（1 年后需还 7,344,000），兑换为 1,000,000 美元存 1 年得 1,050,000 美元，同时按 7.1000 远期卖出美元：1,050,000 × 7.1000 = 7,455,000 人民币，偿还 7,344,000，**无风险利润 111,000 人民币**。套利资金会迅速把远期价格压回平价，所以 CIP 在流动性充裕时成立；当美元流动性枯竭时（如 2008 年），CIP 出现显著偏离，称为交叉货币基差。

**捍卫汇率盯住的账表代价（教学推演案例）**：市场抛售人民币、买入美元，央行为维持 7.2000 的盯住，向市场出售 10 亿美元：

```text
央行（出售外汇储备 10 亿美元，汇率 7.2000）
资产                          | 负债
外汇储备        -10 亿 USD    | 银行准备金            -72 亿 CNY
（折 -72 亿 CNY）             | （基础货币被回笼）

银行体系：准备金 -72 亿，对应持有人民币存款者换成美元流出境外
```

维持固定汇率意味着央行被动回笼基础货币 72 亿，等价于货币紧缩；如果国内本想宽松，两者矛盾，这正是「固定汇率 + 资本自由流动 = 失去独立货币政策」的 T 型账表形式。若紧缩的政治与经济代价过高，或外汇储备不足，盯住就会破裂。

**汇率制度谱系**：

| 制度 | 汇率决定 | 央行义务 | 典型例子 |
| --- | --- | --- | --- |
| 自由浮动 | 市场供求 | 不干预（或极少） | 美元、欧元、日元 |
| 管理浮动 | 市场为主，央行择机干预 | 平滑波动、不设目标 | 多数新兴经济体 |
| 爬行盯住 | 按预设速率贬值或升值 | 维持目标路径 | 部分拉美国家 |
| 货币局 | 法定固定汇率，本币发行 100% 外币储备支持 | 按固定汇率无限兑换 | 香港联系汇率制（发钞行持美元作发行准备） |
| 货币联盟 / 美元化 | 无独立货币 | 放弃货币政策 | 欧元区、巴拿马 |

### 4.4 跨境清算：代理行 Nostro/Vostro 往来户记账与轧差

**术语方向**：同一个往来户，在持有方账簿上叫 Nostro（「本行在对方银行处开立的账户」，资产类科目），在开户行账簿上叫 Vostro（「对方银行在本行处开立的账户」，负债类科目）。

**设定（教学推演案例）**：中国汇出行 A 与巴西收款行 B 均在美国代理行 X 开立美元往来户。汇款人通过 A 向巴西收款人汇出 1,000,000 美元，即期汇率 7.2000，A 的汇出手续费折合 25 美元（180 元人民币），X 扣中间行费 20 美元，B 向收款人扣入账费 15 美元（SHA 模式）。

**步骤 1：A 扣客户资金并发出报文**

- 客户支付人民币 = 1,000,000 × 7.2000 + 180 = 7,200,180 元。

```text
汇出行 A 账簿（单位：CNY / USD）
借：客户活期存款             7,200,180 CNY
贷：外汇买卖（售汇对价）      7,200,000 CNY     ← 对应 1,000,000 USD
贷：手续费收入                    180 CNY
借 7,200,180 = 贷 7,200,000 + 180 ✓
```

A 向客户售出美元，需要动用自身美元头寸，因此记账分为本币层（上表）与外币层。外币层中 A 在 X 的 Nostro 是 A 的资产，汇出时被**贷记**（资产减少）：

```text
A 外币账簿（USD 层）
借：结售汇头寸（卖出 USD 对客户）  1,000,000 USD
贷：Nostro-X（A 的资产减少）        1,000,000 USD
```

同时 A 通过 SWIFT 向 X 发出 MT103（或 pacs.008）报文：「借记本行账户，付 1,000,000 美元给 B 银行，收款人 ×××，费用承担 SHA」。

**步骤 2：X 内部账簿划转（On-us 转账，资金未离开 X）**

```text
代理行 X 账簿（USD）
借：Vostro-A（A 的存款，X 的负债减少）   1,000,000
贷：Vostro-B（B 的存款，X 的负债增加）     999,980
贷：手续费收入（中间行费）                      20
合计：借 1,000,000 = 贷 999,980 + 20 = 1,000,000 ✓
```

**步骤 3：B 记入收款人账户**

```text
收款行 B 账簿（USD）
借：Nostro-X（B 的资产增加）               999,980
贷：收款人存款                             999,965
贷：手续费收入（入账费）                        15
借 999,980 = 贷 999,965 + 15 ✓
```

收款人实收 999,965 美元，1,000,000 - 20 - 15 = 999,965 ✓。整条链路中三家银行的账簿各自借贷平衡，且**资金从未通过 SWIFT 移动，只在 X 的内部账簿上从 Vostro-A 转到 Vostro-B**。

**若 A、B 不共用代理行**：A 的代理行 X 与 B 的代理行 Y 之间需要 RTGS 结算，例如经 Fedwire 或 CHIPS：

```text
X 央行准备金账户  -999,980   →   Y 央行准备金账户  +999,980    （实时全额，终局）
```

### 4.4.2 RTGS 与延迟净额结算（DNS）对比：轧差的节流效果

**设定（教学推演案例）**：银行 A 与 B 当日相互清算美元，A 向 B 付款三笔：100 万、250 万、400 万；B 向 A 付款两笔：180 万、320 万。

| 模式 | 付款笔数 | 结算资金总额 | 峰值流动性需求 |
| --- | --- | --- | --- |
| RTGS（逐笔全额） | 5 笔（实时） | 750 + 500 = 1,250 万 | 取决于收付先后，最坏情形接近 A 需先付 750 万 |
| DNS（日终双边轧差） | 1 笔净额 | 750 - 500 = 250 万（A 付 B） | 250 万 |

轧差节流率 = 1 - 250 / 1,250 = **80%**。这也是 CHIPS 等系统采用持续多边轧差来释放流动性的原因；代价是 DNS 在日终轧差前存在信用风险敞口：若 B 在日终前倒闭，A 已收到的 500 万是否需要返还，取决于法律上轧差的可执行性。

**RTGS 的代价是流动性**：每笔付款需要付款行在央行账户有足够余额；若所有银行都等对方先付款，就形成**支付僵局（Gridlock）**。现实中央行提供日间透支，以合格抵押品换取日间额度，并以优先级队列与流动性节约机制缓解僵局。

**主要系统定位**：

| 系统 | 货币 | 运营 | 性质 |
| --- | --- | --- | --- |
| Fedwire Funds | 美元 | 美国联邦储备体系 | RTGS，央行货币逐笔终局，日均处理额为数万亿美元量级 |
| CHIPS | 美元 | 清算所（The Clearing House） | 日初预存头寸 + 持续多边轧差 + 实时终局，主要处理跨境美元 |
| CNAPS 大额支付系统 | 人民币 | 中国人民银行 | RTGS，2018 年起支持 7×24 小时运行 |
| CIPS | 人民币 | 跨境银行间支付系统（CIPS）运营机构，2015 年上线 | 人民币跨境清算，使用 SWIFT 报文标准与直参、间参模式 |
| TARGET2 / T2 | 欧元 | 欧洲央行体系 | RTGS，欧元区央行货币结算 |

### 4.5 国际卡组四方模式：手续费切分与跨境汇兑

**设定（教学推演案例）**：持卡人在商户刷卡消费 100.00 美元；商户折扣率（MDR）2.50%；交换费 1.65% + 0.10 美元；卡组网络评估费 0.13%。

- MDR = 100.00 × 2.50% = **2.50**；商户到账 = 100.00 - 2.50 = **97.50**；
- 交换费 = 100.00 × 1.65% + 0.10 = 1.65 + 0.10 = **1.75**（归发卡行）；
- 卡组评估费 = 100.00 × 0.13% = **0.13**（归卡组织）；
- 收单行毛利 = 2.50 - 1.75 - 0.13 = **0.62**。

四方分账账表：

```text
【单笔 100.00 美元的四方分账】

  角色        收到                 付出                   净得
  持卡人      (商品)               100.00 (账单)          -100.00
  发卡行      100.00 (持卡人还款)  98.25 (结算给收单行)    +1.75 (交换费)
  卡组织      0.13 (评估费)        --                     +0.13
  收单行      98.25 (行间结算)     97.50 (付商户) + 0.13   +0.62
  商户        97.50                --                     +97.50 (商品款 100 - MDR 2.50)

  闭合校验: 发卡行 1.75 + 卡组 0.13 + 收单行 0.62 = 2.50 = MDR ✓
            收单行 98.25 - 97.50 - 0.13 = 0.62 ✓
```

**跨境刷卡与汇率时点**：人民币持卡人在美国商户消费 100.00 美元，卡组织在结算日以其汇率折算（教学推演案例：7.2000），发卡行再加收 1.5% 跨境手续费。

- 持卡人入账 = 100 × 7.2000 × 1.015 = 720.00 + 10.80 = **730.80 元**。
- 若授权日到结算日之间汇率升至 7.2300：100 × 7.2300 × 1.015 = 733.845，按四舍五入到分为 **733.85 元**，比授权时多 3.05 元。汇率风险在授权与结算之间悬空，由持卡人承担，这也是「授权金额 ≠ 最终入账金额」的原因之一。

**拒付（Chargeback）**：持卡人对交易有争议，发卡行通过卡组向收单行发起拒付，收单行从商户扣回资金，商户可提交证据申诉；拒付窗口通常长达数十至一百多天，因此商户资金存在「已结算但可被追回」的长尾敞口。

## 02.5 极端行情边界与失效条件

### 5.1 货币乘数失效：零准备金与量化宽松

美国 2008 年至 2014 年间，基础货币从约 0.9 万亿美元膨胀到约 4 万亿美元，但货币供应与信贷的增幅远小于基础货币扩张倍数，原因是银行把大量新增准备金作为超额准备金停放在央行（并获得准备金利息），e 大幅上升，乘数下降。2020 年 3 月，美联储把法定准备金率降为 0，教科书的 1/r 完全失去约束意义。结论：货币创造的真实边界是资本充足率、流动性覆盖要求、风险偏好与借款需求，而非单一准备金率。

### 5.2 挤兑：部分准备金制度的本质脆弱

按 10% 准备金率运作的银行，只要 10% 以上的存款人同时提现，就无法用准备金兑付。兜底机制有三层：存款保险（美国联邦存款保险公司 FDIC 的标准保险额度为每储户每银行 25 万美元）、央行最后贷款人（以合格抵押品提供紧急流动性）、监管接管与处置。SVB 案例中约 94% 的存款超过保险额度（此比例为公开报道的估算口径），意味着兜底层的覆盖明显不足，最终依赖监管层的系统性风险例外措施。

### 5.3 收益率曲线与 DCF 的失效点

- **增长率逼近贴现率**：永续增长估值公式 V = CF₁ / (r - g)，当 g 趋近 r，分母趋近 0，估值趋向无穷大；当 g ≥ r，公式无意义。若 r = 8%、g = 7.9%，分母 0.1%，估值为现金流的 1,000 倍，贴现率下降 10 个基点即让公式失去意义，上升 10 个基点则估值腰斩。
- **负利率与零下限**：德国国债与日本国债在部分年份出现负收益率，贴现因子大于 1，现值大于名义和，DCF 数学仍成立，但「时间价值为正」的直觉失效，存款与现金的下限效应使政策利率难以进一步下调。
- **曲线倒挂的统计性而非因果性**：倒挂期可持续数个季度，期间择时失败的概率不低。
- **久期与凸性**：对大幅利率变动，线性久期近似会低估价格上升、高估价格下降，需要凸性项修正。

### 5.4 汇率制度的断裂

- **1992 年 9 月 16 日英镑退出欧洲汇率机制（ERM）**：英格兰银行当日把利率从 10% 上调至 12%，并宣布进一步上调至 15%，仍无法维持英镑对马克的汇率下限，最终退出 ERM。这是「固定汇率 + 资本自由流动」被投机资金清算的经典案例。
- **2015 年 1 月 15 日瑞士央行取消欧元兑瑞郎 1.20 下限**：欧元/瑞郎在盘中一度跌至约 0.85，单日跌幅接近 30%，大量使用杠杆的外汇经纪商与零售账户的保证金被瞬间击穿，部分经纪商因客户负余额而破产。结论：汇率下限类政策是「卖出期权」，市场长期平静积累的是尾部风险。

### 5.5 跨境清算的失效点

- **赫斯塔特风险（Herstatt Risk）**：1974 年 6 月 26 日，德国赫斯塔特银行在德国时间下午被关闭，此前其交易对手已在欧洲时区向其支付了马克，但美国时区的美元腿尚未交付，对手方损失了本金。根源是外汇交易两条腿分属不同时区、不同 RTGS 系统，无法同时结算。后续的 CLS（持续联结结算）通过同步交收（PvP）消除这一风险。
- **时区与日切窗口**：不同货币的 RTGS 开关市时间不同，美元清算错过窗口，款项就会滞留一个自然日以上。
- **合规拦截**：代理行对制裁名单、反洗钱可疑特征做逐笔筛查，命中后冻结或退回，退回路径同样需要逐跳返还并可能再次扣费。
- **制裁切断**：2022 年 3 月起，部分俄罗斯银行被移出 SWIFT 的报文通道，同期其央行持有的外汇资产被冻结，说明报文通路与账户（资产）冻结是两个独立的控制面。
- **代理行去风险化**：全球代理行关系数量近年持续收缩，小国银行失去美元往来户，跨境汇款成本上升。
- **日间透支与支付僵局**：当市场恐慌、银行囤积流动性时，RTGS 里的收款延迟会连锁放大。

### 5.6 卡组的失效点

- **发卡行破产**：卡组结算时发卡行不付款，收单行已垫付商户款项，由卡组结算担保或收单行自担。
- **授权成功但清算缺失**：授权冻结额度后，商户未提交清算文件，额度在若干天后释放，资金未实际移动。
- **重复清算**：同一笔授权被清算两次，导致持卡人重复扣款，需靠清算唯一标识去重与拒付纠错；对应工程约束见 [28 支付核心与多渠道收单网关：智能路由、未知态收敛、重付退回与逆向拒付](28-payment-gateway-routing-and-unknown-state.md)。
- **汇率时点争议**：授权日与结算日汇率不同引发的客诉。

### 自检题一：货币乘数与基础货币回溯

**题目**：央行向银行体系净注入基础货币 B = 5,000 万元。法定准备金率 r = 12%，超额准备金率 e = 3%，公众现金漏损率 c = 25%。求乘数 m、存款总量 D、公众现金 C、货币供应 M = C + D，并验算准备金与基础货币的关系。

**参考答案**：

1. c + r + e = 0.25 + 0.12 + 0.03 = 0.40；
2. D = B / 0.40 = 5,000 / 0.40 = **12,500** 万元；
3. C = 0.25 × 12,500 = **3,125** 万元；
4. M = C + D = 3,125 + 12,500 = **15,625** 万元；乘数 m = 15,625 / 5,000 = **3.125**（也可由 1.25 / 0.40 = 3.125 验证）；
5. 准备金 R = (0.12 + 0.03) × 12,500 = 1,875 万元；
6. 验算：C + R = 3,125 + 1,875 = 5,000 = B ✓。

### 自检题二：两年期债券与远期利率

**题目**：即期利率曲线（年复利）：1 年 3.00%，2 年 3.50%。两年期、票息 4%、面值 100 的年付息债券，理论价格是多少？1 年后到 2 年的隐含远期利率是多少？若该债券市场报价为 100.50，应判断为高估还是低估？

**参考答案**：

1. 第 1 年现金流 4：4 / 1.03 = 3.8835；
2. 第 2 年现金流 104：1.035² = 1.071225；104 / 1.071225 = 97.0851；
3. 理论价格 = 3.8835 + 97.0851 = **100.9686**（精确值 100.968608…）；
4. 远期利率 f(1,2) = 1.071225 / 1.03 - 1 = 1.040024 - 1 = **4.0024%**；
5. 市场报价 100.50 < 理论价 100.9686，差 0.4686，**市场价偏低，债券相对被低估**（存在无风险套利机会的前提是可以把债券拆成零息券复制，实操中需要考虑买卖价差与融资成本）。

### 自检题三：三方多边轧差与流动性节约

**题目**：银行 A、B、C 在一日内产生如下美元付款义务（单位：百万美元）：A 付 B 300；B 付 C 200；C 付 A 100；B 付 A 50；A 付 C 150。（1）计算各行净头寸；（2）多边轧差后的结算总额与流动性节约率；（3）若采用 RTGS 逐笔结算，A 的最大累计付出额是多少？

**参考答案**：

1. A 付出 300 + 150 = 450，收入 100 + 50 = 150，净头寸 = 150 - 450 = **-300**（净付出）；
2. B 付出 200 + 50 = 250，收入 300，净头寸 = 300 - 250 = **+50**（净收入）；
3. C 付出 100，收入 200 + 150 = 350，净头寸 = 350 - 100 = **+250**（净收入）；
4. 校验净头寸之和：-300 + 50 + 250 = 0 ✓；
5. 多边轧差后只需 A 净付出 300，由央行（或清算机构）分别记入 B 的 +50、C 的 +250；结算总额为 300；毛额 = 300 + 200 + 100 + 50 + 150 = 800；节约率 = 1 - 300 / 800 = **62.5%**；
6. RTGS 下 A 向外付出共 450，若其他行付款均晚于 A 的付款到达，A 的最大累计流动性需求为 **450**；若收入先到，需求可降至 300 左右，这说明 RTGS 的流动性需求取决于收付顺序，轧差则把需求固定为净额。
