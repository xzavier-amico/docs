## 13.1 引子：为什么“链上已确认”依然会归零——从重组双花到跨链假消息洗劫

传统金融依靠央行 RTGS 与中央存管机构（CSD）在终局账本上一次性交割（见 [02 货币、信用、利率与跨境清算网](02-money-credit-rates-and-cross-border.md) 与 [03 市场微观结构与金融机构全景](03-market-microstructure-and-six-roles.md)）。公链撤除了中央清算所，节点间靠共识决定账本历史。一旦把“区块浏览器查到记录”或“数个确认”误当成不可撤销终局，清算账本便会在区块重组或跨链验证缺陷下直接穿仓。

### 案例一：2020 年 8 月以太坊经典（ETC）连环 51% 算力重组双花

**2020 年 7 月末至 8 月底**，PoW 公链以太坊经典（ETC）在单月连续遭遇三次 **51% 算力攻击**：
1. **7 月 31 日至 8 月 1 日**：攻击者从算力租赁平台短期租入超越 ETC 全网既有的算力（租金约 **`17.5 BTC`**，当时约合 **`19 万–20 万美元`**），私下挖出更长分叉链后突然广播，造成主链超过 **`3,600` 个区块**发生重组（Reorg）。攻击者此前转入交易所并达当时确认门槛、已兑换提走其他资产的约 **`807,260 ETC`**（约合 **`560 万美元`**），在分叉替代后通过反向转账回到自己地址，净赚逾 25 倍。
2. **8 月 5 日与 8 月 29 日**：同类攻击再度重演，分别重组逾 **`4,000` 块**与 **`7,000` 块**（第二次双花约 **`460,000 ETC`**、约 `320 万美元`），全月累计被重写的历史区块逾 **`14,000` 个**。主流交易所事后被迫把 ETC 充值门槛拉高至数千乃至上万确认。

## 13.2 唯一真问题与反直觉定义：没有中央终审法院，如何定义“不可逆到账”

**最终性（Finality）**指已入块的状态转移在概率或经济成本上变得不可撤销的程度。在开放、存在网络延迟与拜占庭作恶者的公链中，共识与扩容架构共同求解同一个**唯一真问题**：

> **如何在没有中央权威仲裁的开放网络中，为全球乱序交易排出唯一确定顺序，在网络分叉干扰下使全网达成状态一致，并在去中心化校验前提下将“历史账本被推翻”的成本压至业务不可企及的边界？**

工程实践中有五条决定账务生死的核心反直觉事实（见下表对照）：

| 认知维度 | 常见误区 | 为什么是错的（底层机制反直觉真相） | 真实金融与工程代价 |
| --- | --- | --- | --- |
| **Mempool 广播** | 拿到 `txHash` 且显示 `Pending` 就必然进块 | 没有全局内存池；各节点容量有限，低于 `BaseFee`、高价挤兑或 RBF 替价均可致交易被静默逐出 | 把 `Pending` 记作在途扣款完成，交易丢失后出现账实错位或卡池死锁 |
| **PoW 确认数** | 等满 `6` 确认对所有 PoW 公链都绝对不可逆 | Nakamoto 共识只有**概率最终性**；6 确认仅将 `10%` 算力偷袭压至 `0.024%`，面对 `51%` 租算力必被推翻 | 小币种固守浅确认被重组双花（如 2020 年 ETC 全月重组超 `14,000` 块） |
| **PoS 敲定时间** | PoS 每 `12 秒` 出块，所以 12 秒就永久敲定 | 以太坊把出块（`LMD-GHOST`）与终局（`Casper FFG`）拆分；前几个块仍可短重组，`Finalized` 需 `2~2.5 Epoch`（约 `12.8~15 分钟`） | 按 1 确认记账在分叉重组时发生假充值；必须以 `Finalized` 作强闸门 |
| **Rollup 回执** | Layer2 在 `0.3 秒` 返回成功，安全已等同 L1 | `0.3 秒` 仅是中心化排序器（Sequencer）软承诺；硬终局须等批次写入 L1 且过 7 天欺诈窗口或 ZK 验真 | 误信软确认放行大额提现承担回滚风险；官方桥退出强锁 7 天资金 |
| **跨链桥迁移** | 资产通过跨链桥物理移到了目标链，原链无风险 | 资产从未离链，源链锁仓、目标链只放行消息凭据；外部多签或验签被攻破即引发无锚超发或金库搬空 | Ronin 失陷 `6.25 亿美元`、Wormhole 伪造铸出 `12 万 wETH`、Nomad 零根漏洞被盗 `1.9 亿美元` |

## 13.3 机制全景：交易全生命周期、区块重组、Layer2 与跨链桥三大模式

### 13.3.1 一笔链上转账的完整生命周期（以太坊 PoS + EIP-1559）

从私钥签名到最终敲定，一笔转账依次穿越五个物理阶段（前置签名与 `Nonce` 序列化见 [12 数字货币底层运作原理](12-crypto-identity-utxo-and-account-model.md)）：

```text
以太坊转账全生命周期泳道图（0 秒广播 ─► 12 秒入块 ─► ~15 分钟经济敲定）
┌────────────────┬─────────────────┬─────────────────┬──────────────────────┐
│ ① 本地签名     │ ② Mempool 竞价  │ ③ EIP-1559 打包 │ ④ LMD-GHOST → FFG    │
├────────────────┼─────────────────┼─────────────────┼──────────────────────┤
│ 设 nonce/limit │ 校验签名/余额/  │ 提议者(Proposer)│ Slot N (12s):        │
│ maxFeePerGas   │ Nonce 连续性    │ 按有效小费排序  │  块入链 ("Latest")   │
│ maxPriorityFee ├─────────────────┤ 执行并拆分扣费: │  仍可能发生短 Reorg  │
│ 绑 EIP-155     │ 低于 BaseFee 挂 │  - BaseFee 销毁 ├──────────────────────┤
│ chainId 签名   │ 入 Future Queue │  - Tip 归提议者 │ Epoch E+1 (~6.4m):   │
│       │        │ (高价交易可逐出 │  更新全局状态树 │  ≥2/3 投票 Justified │
│       ▼        │  底部低价单)    │  写入 stateRoot ├──────────────────────┤
│ 播至 Mempool   │                 │  与回执成功标志 │ Epoch E+2 (12.8~15m):│
│ 或 Private RPC │ ───► 竞价入选   │                 │  再获≥2/3投票即晋升  │
│                │                 │                 │  "Finalized" (终局)  │
└────────────────┴─────────────────┴─────────────────┴──────────────────────┘
```

**EIP-1559** 摒弃旧式盲拍，将燃气单价裂解为协议自动定价与市场小费两层：
* **动态基础费（`BaseFee`）**：根据上个块实际 `Gas` 耗用相对于目标值（`15,000,000 Gas`，上限 `30,000,000 Gas`）动态调整，满载涨 `+12.5%`、空载降 `-12.5%`。**全部 `BaseFee` 在协议层永久销毁**，彻底切断矿工伪造垃圾交易刷高费率自肥的动机。
* **优先小费（`PriorityFee`）**：用户声明愿付封顶单价 `maxFeePerGas` 与最高小费 `maxPriorityFeePerGas`。入块实际成交单价为 `min(maxFeePerGas, BaseFee + maxPriorityFeePerGas)`，超出 `BaseFee` 的余额归提议者（或 MEV 构建者，见 [18 预言机、MEV 黑暗森林与链上衍生品](18-oracles-mev-dark-forest-and-onchain-perps.md)）。

### 13.3.2 区块重组（Block Reorg）与已确认充值蒸发机制

无论 PoW 的“累计工作量最大链”还是 PoS 检查点未敲定前的 `LMD-GHOST` 最重子树，节点收到更重合法分支时都会立刻切换主链视图：

```text
区块重组（Reorg）抹除已确认入账的物理路径
主网视图 (t2): [H] ─► [A1: Tx_充值平台] ─► [A2] ─► [A3]  ◄── 平台按 3 确认放行提现
暗链释放 (t3): [H] ─► [B1: Tx'_同Nonce/UTXO转回己方] ─► [B2] ─► [B3] ─► [B4] (反超!)
切换终局 (t4): A1..A3 降级为孤块。因 Tx 的输入/Nonce 已被 B1 抢先消耗，Tx 永久作废，
               平台热钱包已打出的提现资产不可追回，留下永久资不抵债缺口。
```

扫块系统若未检查父哈希连续性并硬等深度敲定（见 [36 数字货币托管与充提币系统（下）](36-chain-indexer-reorg-defense-and-nonce.md)），就会在分叉切换瞬间暴露于假充值打击。

### 13.3.3 不可能三角与 Layer2 Rollup 扩容双路径

**不可能三角**揭示单层公链无法同时极致满足**去中心化、安全性、可扩展性**：无节制放大 L1 区块将迫使普通全节点因带宽与 SSD I/O 淘汰，全网滑向少数机房垄断。**Layer2 Rollup** 通过“**执行在 L2、数据可用性（DA）与终局裁决锚定 L1**”破局。配合以太坊 **EIP-4844** 新增的 **`Blob`** 通道（每块目标 `3` 个、上限 `6` 个，单 Blob 固定 `128 KB = 131,072 Bytes`），Rollup 批次数据不再进入昂贵的 EVM 永续存储，而是独立定价并在共识节点留存约 **`18 天`（`4,096 Epochs`）** 后自动剪枝，将 DA 成本骤降 1~2 个数量级。

```text
Optimistic Rollup vs ZK-Rollup 核心结算路径对比
┌──────────────────────────────────────────────────────────────────────┐
│ 【Optimistic Rollup (欺诈证明)】                                     │
│  L2 批压缩全量原始交易 ─► 写入 L1 Blob + 提交新状态根 S_new          │
│     └─► 进入【7 天挑战窗口】(靠 EIP-4844 18 天 Blob 保留期提供证据) │
│         无有效质疑 ─► 满 7 天后官方桥放行提款                        │
│         有人质疑   ─► 交互式二分定位争议步 ─► L1 合约裁决并罚没作恶金│
├──────────────────────────────────────────────────────────────────────┤
│ 【ZK-Rollup (零知识有效性证明)】                                      │
│  L2 计算新状态根 + 状态差分(State Diff) + 数学证明(SNARK/STARK)      │
│     └─► 连同压缩差分写入 L1 Blob ─► L1 合约毫秒级验真证明            │
│         验真通过且 L1 敲定即刻获硬终局 (无需 7 天等待期)             │
└──────────────────────────────────────────────────────────────────────┘
```

| 维度 | Optimistic Rollup | ZK-Rollup |
| --- | --- | --- |
| **信任假定** | 假定 7 天内至少有 **1 个诚实观察者**在线提交欺诈证明 | **密码学数学不可伪造性**：作假状态无法算出合法证明 |
| **上链核心 DA** | 必须提交**完整压缩交易明细**（供全网重放检验） | 可仅提交**最终状态差分（State Diff）**（高频反复读写省大量空间） |
| **L1 验证开销** | 正常无争端时几乎零验证算力成本 | 链下需 GPU 集群算证明；L1 每次验真耗费约 `30万–50万 Gas` |
| **官方桥退出期** | **强制 `7 天`**（抗衡 L1 交易审查攻击所需时间安全垫） | **数十分钟至数小时**（依赖证明打包批次周期与 L1 Finalize） |

```text
跨链桥三大模式资金与消息拓扑
(1) 锁定铸造 (Lock & Mint):
    用户 ─► [链A 金库锁 100 ETH] ─► 外部多签/MPC 委员会背书 ─► [链B 铸出 100 wETH]
```

| 模式对比 | 资产本质 | 核心信任根 | 最坏穿仓爆炸半径 |

## 13.4 核心定量推演（上）：EIP-1559 费用演化、PoW 概率最终性与 PoS 罚没算账

### 一、EIP-1559 动态基础费连续区块演进与单笔精确结算（教学推演案例）

以太坊执行层设定区块目标容量 $G_{\text{target}} = 15,000,000\text{ Gas}$，硬上限 $G_{\text{limit}} = 30,000,000\text{ Gas}$，单块调节最大步长因子为 $\frac{1}{8}$（$\pm 12.5\%$）：

$$\text{BaseFee}_{t+1} = \text{BaseFee}_{t} \pm \left\lfloor \text{BaseFee}_{t} \times \frac{|G_{\text{used}, t} - G_{\text{target}}|}{G_{\text{target}}} \times \frac{1}{8} \right\rfloor$$

设 `Block 100` 起始 **`BaseFee = 32.000000000 Gwei`**（`32,000,000,000 Wei`）。用户发送一笔合约交易：`gasLimit = 100,000`、实际执行 **`65,000 Gas`**、`maxFeePerGas = 38.000000000 Gwei`、`maxPriorityFeePerGas = 2.000000000 Gwei`。连续四块负载演化如下：
1. **`Block 100` 满载（`30,000,000 Gas`）**：上调 `+12.5%`，$\text{BaseFee}_{101} = 32 \times 1.125 = \mathbf{36.000000000\text{ Gwei}}$。
2. **`Block 101` 满载（`30,000,000 Gas`）**：继续上调 `+12.5%`，$\text{BaseFee}_{102} = 36 \times 1.125 = \mathbf{40.500000000\text{ Gwei}}$。因 `maxFeePerGas (38.0) < 40.5`，用户交易被协议挂起冻结在 Mempool 无法入块。
3. **`Block 102` 空载（`0 Gas`）**：下调 `-12.5%`，$\text{BaseFee}_{103} = 40.5 \times (1 - 0.125) = \mathbf{35.437500000\text{ Gwei}}$（`35,437,500,000 Wei`）。
4. **`Block 103` 解冻入块结算**：满足 `35.4375 <= 38.0`，交易执行完毕并精确分账：
   * **有效单价**：$\min(38.0000,\ 35.4375 + 2.0000) = \mathbf{37.437500000\text{ Gwei}}$（小费实拿全额 `2.0000 Gwei`）；
   * **总扣燃料费** $= 65,000 \times 37.4375\text{ Gwei} = \mathbf{2,433,437,500,000,000\text{ Wei}} = \mathbf{0.002433437500\text{ ETH}}$；
   * **协议永久销毁** $= 65,000 \times 35.4375\text{ Gwei} = \mathbf{2,303,437,500,000,000\text{ Wei}} = \mathbf{0.002303437500\text{ ETH}}$；
   * **验证者小费** $= 65,000 \times 2.0000\text{ Gwei} = \mathbf{130,000,000,000,000\text{ Wei}} = \mathbf{0.000130000000\text{ ETH}}$。
   * 销毁与小费精确加和等于总扣款，未耗用的 `35,000 Gas` 额度不予扣除。

### 二、PoW 算力竞争与“6 个确认”双花成功概率推演

按中本聪白皮书泊松与随机游走模型，设诚实网络算力占比 $p$、攻击者占比 $q = 1 - p$（$q < 0.5$）。等待 $z$ 个确认期间，攻击者追赶期望步数 $\lambda = z \cdot \frac{q}{p}$，追平反超主链的成功概率为：

$$P_{\text{success}}(z, q) = 1 - \sum_{k=0}^{z} \frac{\lambda^k e^{-\lambda}}{k!} \left[ 1 - \left(\frac{q}{p}\right)^{z - k} \right]$$

以 $q = 0.10$（$q/p = 1/9$）、`z = 1` 验证：$k=0$ 项给出 $e^{-1/9}(1-1/9) \approx 0.894839 \times 0.888889 = 0.795413$，$k=1$ 项括号为零，故 $P_{\text{success}}(1, 0.10) = \mathbf{20.4587\%}$。不同算力与确认数对照如下：

| 攻击者算力占比 $q$ | `z = 1` 确认 | `z = 3` 确认 | `z = 6` 确认 | `z = 12` 确认 | `z = 20` 确认 | 风控结论 |
| --- | --- | --- | --- | --- | --- | --- |
| **`10%`** | `20.4587%` | `1.3172%` | **`0.0243%`** | `< 0.0001%` | `< 0.0001%` | `6` 确认仅能把 10% 算力压至万分之 2.4 |
| **`20%`** | `41.5899%` | `10.3242%` | **`1.4251%`** | `0.0294%` | `0.0002%` | 20% 算力下 6 确认仍有 1.4% 高双花风险 |
| **`30%`** | `62.7749%` | `32.4584%` | **`13.2111%`** | `2.3584%` | `0.2480%` | 30% 算力下 6 确认几乎失效，须深确认 |
| **`35%`** | `73.0625%` | `48.4459%` | **`28.2171%`** | `10.2362%` | `2.7659%` | 1/3 算力时等待 12 块仍有逾 10% 成功率 |
| **`≥ 51%`** | **`100.0000%`** | **`100.0000%`** | **`100.0000%`** | **`100.0000%`** | **`100.0000%`** | **算力占优期间任何固定确认数终将失守** |

可见“6 确认”的真正护城河并非数字 6，而是比特币全网算力极度庞大、无法在外部租赁市场以低于双花收益的成本凑足 $q > 20\%$ 的哈希率。

### 三、以太坊 PoS 时间轴与 Slashing 相关性罚没定量账本（教学推演案例）

## 13.5 核心定量推演（下）：Rollup 成本摊薄、7 天流动性贴现与跨链桥穿仓账本

### 一、Layer2 Rollup 批次 DA 摊销成本算账（教学推演案例）

设以太坊 L1 执行层 `BaseFee = 20 Gwei`、`ETH = $3,000`。L1 单笔原生 ETH 转账固定消耗 `21,000 Gas`，费用为 $21,000 \times 20\text{ Gwei} = \mathbf{0.00042000\text{ ETH}}\ (\mathbf{\$1.26})$。

某 ZK-Rollup 批量打包 **`8,000` 笔**转账（压缩后平均 `14 Bytes/笔`，总载荷 `112,000 Bytes` 装入 **`1 个 EIP-4844 Blob`**，按完整 Blob `131,072 BlobGas` 结算，设 `blobBaseFee = 5 Gwei`，L1 合约验证证明及更新状态根耗用执行 `350,000 Gas`）：
1. **L1 验真执行费** $= 350,000 \times 20\text{ Gwei} = \mathbf{0.00700000\text{ ETH}}$；
2. **L1 Blob 数据费** $= 131,072 \times 5\text{ Gwei} = \mathbf{0.00065536\text{ ETH}}$；
3. **整批 L1 合计成本** $= 0.00765536\text{ ETH}\ (\mathbf{\$22.96608})$；
4. **单笔 L2 分摊成本** $= \frac{0.00765536}{8,000} = \mathbf{0.00000095692\text{ ETH}}\ (\approx \mathbf{\$0.00287})$，较 L1 直接执行下降 **`438.9 倍`**！

| 维度 | L1 原生逐笔执行 | ZK-Rollup 批次（1 Blob 装 8,000 笔） | 降本幅度 |
| --- | --- | --- | --- |
| **执行计算消耗** | `21,000 Gas/笔`（全网 `1.68 亿 Gas`） | 整批共享 `350,000 Gas` 验真 | 摊薄 `480 倍` |
| **单笔综合成本** | **`0.00042000 ETH`（`$1.26`）** | **`0.0000009569 ETH`（`$0.00287`）** | **降至 `1 / 438.9`** |

### 二、Optimistic Rollup 7 天挑战期流动性贴现定价（教学推演案例）

由于官方标准桥必须锁仓 **`7 天`**，追求秒级到账的用户只能向流动性做市桥支付基点折价换取 L1 即时垫付。设某用户即时撤回 **`100,000 USDC`**，做市商（LP）收取 **`15 bps`（`0.15%` = `150 USDC`）** 服务费并自担 7 天官方桥等待周期。一年 `365 天` 可周转 $365 / 7 \approx 52.1429$ 次，做市商占压资金的年化毛单利回报（APR）为：
$$\text{APR}_{\text{LP}} = 0.0015 \times \frac{365}{7} = \mathbf{7.8214\%}\quad (\text{复利 }\text{APY} = (1+0.0015)^{365/7}-1 = \mathbf{8.1291\%})$$
这意味着当全市场无风险资金利率为 `5.00%` 时，垫付底线仅 **`9.59 bps`**；而当牛市推高链上借贷年化利率至 `18.00%` 时，LP 盈亏平衡报价立刻跃升至 $18.00\% \times \frac{7}{365} = \mathbf{34.52\text{ bps}}$，直接解释了牛市快速跨链费率走高的资金成本机理。

## 13.6 极端行情边界与失效条件：Mempool 雪崩、PoS 停摆与跨链连环挤兑

1. **连续满块下 `BaseFee` 指数暴涨与 Mempool 局部逐出**：极速清算踩踏时，连续 `10` 个满载区块可把 `BaseFee` 推高 $1.125^{10} \approx \mathbf{3.247\text{ 倍}}$，连续 `20` 块（4 分钟）暴涨 **`10.55 倍`**！内存池容量（约 4,000~5,000 笔）饱和后开始从头部逐出早期低价交易，导致 `Nonce` 队列断层死锁（见 [12 数字货币底层运作原理](12-crypto-identity-utxo-and-account-model.md)）。
2. **中小 PoW 公链遭遇算力租赁降维打击**：外部算力市场可随时按小时租入碾压全网的哈希功率，令所有静态小确认阈值（`6`、`20` 甚至 `60` 块）瞬间丧失防护效用。
3. **PoS 超过 1/3 验证者掉线导致的 Finality 停摆**：**2023 年 5 月 11 日与 12 日**，以太坊主网两次因客户端高负载异常导致投票率跌破 2/3，最终性分别停摆 **`3 Epochs`（约 25 分钟）** 与 **`8 Epochs`（约 1 小时）** 并触发 **Inactivity Leak** 才得以恢复。托管系统若死锁等 `Finalized` 则全网充值停摆 1 小时，若盲目放开降级为 `Latest` 则在分区恢复重组时直面双花穿仓。
4. **Rollup 排序器单点宕机与 L1 逃生通道踩踏**：单中心化 Sequencer 崩溃或遭拒绝服务攻击时，用户虽能绕过排序器向 L1 强制包含合约（Force Inclusion）自救，但全市场恐慌并发挤压 L1 区块将推高逃生 Gas 费用至百倍，且 Optimistic Rollup 仍要忍受 `7 天` 等待导致合约保证金强平超时（参见 [11 金融风险全景与经典崩盘解剖](11-financial-risk-taxonomy-and-crashes.md)）。
5. **跨链桥包装资产脱锚向借贷协议传染**：锁定铸造桥一旦出现储备亏空或单控私钥失联，目标链包装币立刻折价脱锚；若目标链借贷或清算预言机仍按 `1:1` 原生美元/ETH 估值（见 [15 稳定币与 RWA 运转全解](15-stablecoins-mechanisms-depegs-and-rwa.md) 与 [18 预言机、MEV 黑暗森林与链上衍生品](18-oracles-mev-dark-forest-and-onchain-perps.md)），套利者会立即拿折价包装币抵押掏空全链真实流动池。

## 13.7 术语正本清源与工程约束映射

### 一、易混共识与扩容术语正本清源表

| 易混术语对 | 金融与协议本质精准辨析 | 对托管、清结算与后端系统的直接约束 |
| --- | --- | --- |
| **`Latest` vs `Finalized`** | `Latest` 只是当前最重分叉顶部，随时可能短重组退回；`Finalized` 经过双周期 2/3 检查点敲定，篡改需毁 1/3 质押 | 机构托管、大额入账与跨链铸币禁信 `Latest`，必须锚定节点共识 `finalized` 状态 |

6. **未敲定在途账与可动用净值的复式隔离**：处于 `Latest`、L2 软确认或 7 天挑战在途的资产只能计入内部复式账本“待确认过渡科目”，严禁提前释放可提现或抵押额度；日终必须在统一敲定块高快照下核平链上余额，参见 [19 CeFi vs DeFi 全维度对照](19-cefi-vs-defi-custody-and-proof-of-reserves.md) 与 [27 多层对账引擎与差错闭环](27-multi-tier-reconciliation-and-auto-healing.md)。

### 三道硬核自检推演题（附逐分逐毫精确答案）

#### 题目 1：EIP-1559 连续跳变、卡单恢复与 `maxFeePerGas` 挤压小费算账
设某链 `Block 200` 的 `BaseFee = 24.000 Gwei`（目标 `15M Gas`，上限 `30M Gas`，最大步长 `1/8`）。用户发出交易：`maxFeePerGas = 30.000 Gwei`、`maxPriorityFeePerGas = 2.000 Gwei`、实耗 `80,000 Gas`。若随后 `Block 200` 消耗 `30M Gas`、`Block 201` 消耗 `30M Gas`、`Block 202` 消耗 `7.5M Gas`：
1. 求 `Block 201`、`202`、`203` 各自精确的 `BaseFee`；
2. 该交易在哪个块被拒卡池、哪个块恢复入块？最终实际成交单价、实得小费单价、销毁 ETH 与验证者收入各是多少？

**【完整推演答案】**
1. **逐块 `BaseFee`**：`Block 200` 满载涨 `12.5%` 得 $\text{BaseFee}_{201} = 24 \times 1.125 = \mathbf{27.000000000\text{ Gwei}}$；`Block 201` 满载再涨 `12.5%` 得 $\text{BaseFee}_{202} = 27 \times 1.125 = \mathbf{30.375000000\text{ Gwei}}$；`Block 202` 半载（$(7.5\text{M}-15\text{M})/15\text{M} \times 1/8 = -6.25\%$）降得 $\text{BaseFee}_{203} = 30.375 \times 0.9375 = \mathbf{28.476562500\text{ Gwei}}$。
2. **入块与分账**：在 `Block 202` 因 `30.000 < 30.375` 卡池，在 `Block 203` 解冻打包。有效单价 $= \min(30.000,\ 28.4765625 + 2.000) = \mathbf{30.000000000\text{ Gwei}}$；小费被封顶挤压至 $30.000 - 28.4765625 = \mathbf{1.523437500\text{ Gwei}}$。总扣款 $= 80,000 \times 30 = \mathbf{0.002400000000\text{ ETH}}$；销毁 $= 80,000 \times 28.4765625 = \mathbf{0.002278125000\text{ ETH}}$；验证者小费 $= 80,000 \times 1.5234375 = \mathbf{0.000121875000\text{ ETH}}$（和为 `0.0024 ETH`）。

#### 题目 2：PoW 小币种算力租赁双花 ROI vs PoS 经济最终性罚没代价
**场景 A（教学推演案例）**：某小市值 PoW 币诚实算力 `100 TH/s`、出块 `15 秒`。交易所要求 **`20` 确认**入账。外部租用 `125 TH/s` 费率为 **`$3,600 / 小时`**（`$1 / 秒`）。① 攻击者租入 `125 TH/s` 后占全网算力多大比例？按此算力私挖反超 `21` 块期望耗时几秒？② 若攻击者存入 `$50,000` 并全程租算力 `6 分钟`（另含 `$140` 滑点费），净套利多少？交易所至少须把 `$50,000` 门槛设为多少确认数才能使算力租金高于 `$50,000`？
**场景 B**：以太坊 PoS（全网质押 `3,200 万 ETH`，`ETH = $3,000`）若控制 `34%` 节点双投推翻已敲定历史，至少销毁多少美元？

**【完整推演答案】**
1. **占比与耗时**：合计算力 `225 TH/s`，占比 $q = 125/225 \approx \mathbf{55.56\%}$；平均出块缩为 $15 \times (100/125) = \mathbf{12\text{ 秒}}$，挖出 `21` 块仅需 $21 \times 12 = \mathbf{252\text{ 秒}}$（快于诚实链 20 块的 300 秒）。
2. **ROI 与确认阈值**：`360 秒` 租金 `$360` 加滑点共计 **`$500`**，净套利 `$50,000 - $500 = \mathbf{\$49,500}$`。欲使租金 $> \$50,000$ 须拖延攻击超过 `50,000 秒`，对应确认门槛 $z > 50,000 / 15 \approx \mathbf{3,334\text{ 块}}$。
3. **PoS 销毁代价**：$34\%$ 违规触发 $3 \times 34\% \ge 100\%$ 全额归零罚没，销毁 $32,000,000 \times 34\% = \mathbf{10,880,000\text{ ETH}}$，价值 $\mathbf{\$326.4\text{ 亿美元}}$。

#### 题目 3：ZK-Rollup 批次 DA 摊薄与 7 天流动性做市利率平衡
设主网 `BaseFee = 30 Gwei`、`ETH = $3,000`，单笔 L1 ERC-20 转账耗 `65,000 Gas`。某 ZK-Rollup 合并 **`10,000` 笔**转账产生的 State Diff 为 `96,000 Bytes`，恰好占用 **`1 个 Blob`**（`131,072 BlobGas`、`blobBaseFee = 2 Gwei`），加 L1 证明验真耗用执行 **`450,000 Gas`**。另一侧，某 Optimistic Rollup 用户欲即时撤出 **`100,000 USDC`** 至 L1，流动性桥收取 **`12 bps`** 服务费以省去 `7 天` 官方桥等待期。求：① L1 直转与 ZK-Rollup 单笔分摊成本及降本倍数；② 快速桥收取多少美元费用？做市商年化毛单利 APR 是多少？若资金外部成本为 **`8.00%` APR**，盈亏平衡费率应为多少 `bps`？

**【完整推演答案】**
1. **成本对比**：L1 直转 $= 65,000 \times 30\text{ Gwei} = \mathbf{0.001950\text{ ETH}}\ (\mathbf{\$5.85})$。ZK-Rollup 整批花费 $= 450,000 \times 30\text{ Gwei} + 131,072 \times 2\text{ Gwei} = 0.013500000 + 0.000262144 = \mathbf{0.013762144\text{ ETH}}\ (\$41.286432)$；均摊单笔 $= 0.013762144 / 10,000 = \mathbf{0.0000013762144\text{ ETH}}\ (\approx \mathbf{\$0.004129})$，降本倍数 $= 0.001950 / 0.0000013762144 \approx \mathbf{1,416.93\text{ 倍}}$。
2. **流动性定价**：服务费 $= 100,000 \times 0.0012 = \mathbf{120.00\text{ USDC}}$；LP 单利 $\text{APR} = 0.0012 \times \frac{365}{7} \approx \mathbf{6.2571\%}$；在 `8.00%` 资金成本下，盈亏平衡点为 $8.00\% \times \frac{7}{365} \approx \mathbf{15.34\text{ bps}}$（故 `12 bps` 实为负利差补贴报价）。
