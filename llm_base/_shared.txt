# 【内部】llm_base 写作唯一事实源

> 本文件不是章节，不进入目录、不进进度、不参与自检。所有写作任务必须先读完本文件与 [`0-summary.md`](0-summary.md)。
> 与本文件冲突的细节，一律以**本文件**为准；需要新增既定事实，先改本文件，再改章节。

## A. 全书立场（不可改口径）

> **这套书不教你怎么「用 AI」，教你怎么不被 AI 骗——不被它骗，不被卖它的人骗，也不被自己的期待骗。**

**三本账可以互相兑换**：质量、钱、时间。
**五条红线不参与兑换**：事实、权限、隐私、版权、不可逆。

写作时的实际含义：**任何「提示词写严一点就好了」的结论都不合格。** 提示词能提高服从概率，改不了权限，也给不出回执与证据。

## B. 四个定位问题（每篇至少用一次）

| # | 问 | 防的是 |
| --- | --- | --- |
| 1 | 这句话是谁说的？模型、应用、工具，还是人？ | 把模型的措辞当成系统的承诺 |
| 2 | 它这一轮看见了什么？材料真送进去了吗？ | 把「文件里有」当成「模型看见了」 |
| 3 | 这是提议、事实，还是已经执行？ | 把「它说办好了」当成办好了 |
| 4 | 我拿什么独立验证？原文、回执、对照，还是它自己的复述？ | 把「它说它检查过」当成检查 |

## D. 贯穿案例：秋季团建（唯一版本，不得改动）

**背景**：虚构公司，39 人参加，当天往返。今天是 **10 月 8 日**。

| 项 | 既定事实 |
| --- | --- |
| 活动日期 | **10 月 25 日（周六）**，当天往返 |
| 通知版本 | v1 写「10 月 18 日（周六）」→ **已作废**；v2 改为 10 月 25 日，并写明 v1 作废。雨天方案写「待确认」 |
| 名单 | 系统导出 **42 条记录**，其中 **3 条是同一人的重复提交** → 去重后 **39 人** |
| 预算 | 总额 **15,600 元**（按 39 人、人均 400 计） |
| 场地 A（山脚营地） | 人均 **260 元**，含午餐、场地、保险 → 39×260 = **10,140** |
| 包车 | 2 辆 × 1,800 = **3,600** |
| A 方案合计 | 10,140 + 3,600 = **13,740**，余 **1,860** |
| 场地 B（湖边基地） | 人均 **310 元**；自称上限 40 人；**合同未签、档期未确认** → 39×310 = 12,090；+3,600 = **15,690**，**超预算 90 元** |
| 饮食 | 39 人中 **2 人素食**，**1 人花生过敏**（须与场地确认） |
| 权限 | 可起草、可查名单；**不可群发、不可付定金、不可改名单** |
| 未定项 | 雨天室内备选未确认；B 场地档期未确认 |

**写作纪律**：
- 任何章节引用这组数字前先自查一遍算式；**不允许出现与本表不同的金额、人数、日期**。
- 需要新事实（例如「谁在群里说了什么」）时，先加进本表，再使用。
- 案例是虚构的，首次出现处标注「虚构」，不冒充实测。

**六本账**（每篇只增不改，读者最终得到一张填满的表）：

| 账目 | 记什么 | 首次出现 |
| --- | --- | --- |
| 材料 | 每份文件的版本、日期、适用范围 | 05 |
| 版本 | 哪份取代哪份、谁说的 | 05 |
| 约束 | 硬约束、可用默认、未定项 | 09 |
| 权限 | 可读 / 可写 / 可发 / 可付 | 16 |
| 证据 | 每条结论对应哪句原文、哪张回执 | 10 |
| 预算 | Token、时间、金额上限 | 19 |

## F. 文风

- **先图后术语**：读者先看到「谁把什么东西给了谁」，再看到名词。
- **标题是判断句**，正文第一句必须是可复述的结论，不是「本章将介绍……」。
- **反面先于正面**：先说常见错法错在哪，再说对法。
- **类比必须写失效点**：工作台、账本、CPU、操作系统都可以用，但每个都要写「到这一步就不成立了」。
- 参考文风样本：[`_sample-inference.md`](_sample-inference.md)（内容作废，只学密度与图解方式）。

**禁止**：
- 任何真代码、伪代码、命令行、API 报文、JSON 报文（结构化输出可以画成**表格**，不贴 JSON）。
- 无来源的准确率、性能倍数、价格、日期；「业界普遍认为」「研究表明」。
- 把注意力权重图、模型自述当解释。
- 品牌排名、产品按钮教程。
- 占位词：`待撰写`、`TODO:`、`TBD`、`待补充`、`此处省略`。

## G. 数字与证据分级

| 级别 | 是什么 | 怎么写 |
| --- | --- | --- |
| 一级 | 论文、正式规范、官方文档 | 可直接引用，标版本与查阅日期 |
| 二级 | 官方博客、模型卡、产品帮助页 | 必须标「某产品、某版本、某日查阅」 |
| 三级 | 媒体报道、二手总结 | 只作线索，不作论据 |
| 示意 | 教学用的模拟数字、虚构案例 | **必须显式写「示意」「虚构」** |

**任何数字出现时，读者要能回答：谁的数、什么条件下、量的哪一段。**

## H. 案例篇额外要求

四个实战篇（29–32）必须包含「**先犯一个典型错，再改对**」的对照，并交出可复制的自然语言产物（任务卡、规格、清单），不交代码。

| 篇 | 必须纠正的典型错 |
| --- | --- |
| 29 短剧 | 反转靠临时补信息而非回收伏笔；相邻镜头道具/服装跳变 |
