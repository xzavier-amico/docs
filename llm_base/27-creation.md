## 27.1 引子：一份「看着不错」的初稿

**虚构场景。** 10 月的一个下午，一个写短剧的人把材料交给了助手：三集，每集八分钟，竖屏，主角是开末班公交的女人，禁区是不许出现真实线路名。两个小时后，她拿到一份分集大纲和一集样章。

她读第一遍，觉得不错。句子干净，节奏也在，结尾还有一个不解释的镜头。她甚至想，这次能省两天。

第二遍，读到第四场，她停住了。不是哪句话写错了。是她说不出这个女人此刻想要什么。第一场她要保住这份工作，第二场她似乎在等一个人，第四场她突然开始追一个陌生人——三件事单独看都成立，但没有一件事是从上一件事长出来的。

她回头查，问题更多：第二场说那块怀表是父亲留下的，第六场成了母亲的；第一场是雨夜，第三场所有人的衣服都是干的；全篇跟着女主，第六场却插了一段男主在另一座城市的独白，而女主并不在场。还有一件事她说不上来，只觉得每读三段就想跳一下——每一段的最后一句，都像在替她总结人生。

这份稿子最难受的地方在于：**它没有一句话是错的。** 语法对，意象也说得过去，没有明显的胡话。它的失败不在句子层，在承重层。

她做了大多数人会做的事：在同一个对话里说「再润色一下，让它更深刻、更有电影感」。二十分钟后，稿子更顺了，句子更漂亮，怀表的冲突还在，视角的越界还在，而且新加了三段抒情。

原因很简单：**「润色」这个指令指向的是句子，而她的问题在句子之间。** 更麻烦的是，每润色一次，她昨天定过的东西就掉一格——第六场原本改对的称呼，在第三版里又回到了第一版的写法。

于是她把这件事归成一句很常见的话：「AI 写东西，就是看着不错，用不了。」

这句话对了一半。它确实「看着不错」，但它不是「用不了」，是**被要求同时做两件互相拆台的事**。拆开之后，两件都能用；混在一起，两件都做不好。

## 27.2 唯一真问题：单句合格，整篇散架

先把「写得不好」拆成四种完全不同的毛病。它们的修法互不通用，混成一句「再改改」，就会一直在句子层打转：

| 你看到的 | 真正发生的事 | 该修哪一层 |
| --- | --- | --- |
| 十个方向都差不多，选不出 | 候选没有分开，只有一个方向被换了十种说法 | 发散的输入：约束 |
| 前后对不上，道具、称呼、时间乱 | 昨天定过的决定，这一轮不在桌上 | 收敛的输入：账本 |
| 每段都成立，整篇不知道在说什么 | 没有承重的东西——人物要什么、戏往哪走 | 人：主题 |
| 读三段就想跳，说不出哪里坏 | 句子的形状太平均，每段都收成一个总结 | 约束：反例 |

由此得到本篇的唯一真问题：

> **AI 写的初稿为什么「看着不错」，拍出来或读下去就散？**

短答案只有一句：**因为它最擅长的两件事被要求同时做，而这两件事互相拆台。**

它擅长在给定前缀下给出「下一个最顺的片段」——所以单句好看（P1）。它不擅长记住上一轮定过什么——所以整篇对不上（P2）。而当你要求它「既要多、又要好、又要一致」时，它会优先满足「顺」，因为「顺」是它唯一能直接计算的东西；「好」和「一致」都要靠外部标准，而外部标准不在它的打分表里。

所以操作版本的问题是：

> **什么时候该让它多给，什么时候该让它别动？**

本篇的判断先放在这里，后面六节都在替它作证：

> **创作里 AI 最擅长的是「给出足够多的候选」，最不擅长的是「记住你昨天定过什么」。所以要把这两件事拆成两轮，不要混在一次对话里。**

这句话容易被读成一句流程建议——「先头脑风暴，再写正文」，谁都知道。它不是。它说的是**两种输入不能同时上桌**：

- 发散轮要的输入是**差异**：题材、约束、禁区，越不同越好；设定簿最好别进来，进来就会把它按住。
- 收敛轮要的输入是**一致**：设定簿、上一章原文、称呼表、伏笔账，越全越好；「再给我几个备选」最好别进来，进来就会把它放飞。

同一次对话里，这两套输入会互相污染。账本在场，它不敢乱想；约束在场，它不肯守旧。你以为自己在「一次说清」，实际上是在让它一边想一边审——而这两件事在同一段前缀里，只能妥协出一个平均值。

### 四问在这一篇长什么样

| # | 问 | 在创作里问什么 |
| --- | --- | --- |
| 1 | 这句话是谁说的？ | 这个主题、这个结局，是你定的，还是它在第一轮「顺便」替你定的？ |
| 2 | 它这一轮看见了什么？ | 这一轮它手里有设定簿吗，还是只有上一段正文？ |
| 3 | 这是提议、事实，还是已经执行？ | 「伏笔已经埋好」是它的提议，还是正文里真有那一句？ |
| 4 | 我拿什么独立验证？ | 拿连续性表逐条对照，还是问它「有没有矛盾」？ |

第 2 问决定这一轮能做什么，第 4 问决定你能不能信。这两问在创作里比在别处更容易被跳过，因为「读起来顺」太像一种验证了。

## 27.3 一张图：两轮，四种角色

先把整条链摊开。注意图中的「账本」不是模型的一部分，它是一个外部文件，每一轮都要重新放上桌：

```text
第一轮 · 发散：要的是"互不相同"，不是"好"
  人：题材 + 十条不同的硬约束（受众 / 视角 / 结局 / 篇幅 / 禁区……）
        │
        ▼
  模型：10 个方向，每个三行——一句话冲突 / 谁最痛 / 结尾落在哪
        │   本轮禁令：不排序、不推荐、不自我评价
        ▼
  人：圈 2 个（判据不是"最好"，是"我说得出想看的理由"）
        │
        ▼
第二轮 · 收敛：一次只展开一个方向
  人：方向 B + 设定簿 + 这一次的交付 + 反例约束
        │
        ▼
  模型：章纲 / 场景 / 样章（只给一个方向，不给备选）
        │
        ▼
  人：连续性表逐条对照 + AI 味标记 → 定点返修
        │
        └──▶ 账本更新（动机 / 时间 / 视角 / 道具 / 伏笔）
```

四种角色各自负责什么，一张表说完：

| 谁 | 发散轮做什么 | 收敛轮做什么 | 不负责什么 |
| --- | --- | --- | --- |
| **人** | 给约束、圈 2 个、决定不要哪 8 个 | 定「想说什么」、核连续性、签字 | 逐句写；也替不了自己的判断 |
| **应用** | 组装题材、约束、禁区 | 组装设定簿、上一章原文、反例约束 | 判断哪一版更好 |
| **模型** | 在十条不同约束下各给一个方向 | 在一个方向上展开成场景 | 记住昨天；保证前后一致 |
| **账本**（外部文件） | 记下被圈的 2 个与被否的 8 个 | 记动机、时间、视角、道具、伏笔 | 自动更新；自动被读取 |

这张图里少了一个在别处很重要的角色：**工具 / 运行时**。创作几乎不触发「执行」——不付款、不改数据、不发消息。它唯一的不可逆动作是**发布**，而发布发生在你按下按钮的那一刻，不在生成的那一刻。所以创作的风险结构和 15–20 篇讲的不一样：这里没有「越权付款」，只有「署了你的名」和「发出去就收不回」。这也解释了为什么这一篇的重点不是权限，而是**归属**——读者会认为这些话是你说的。

### 两种输入，不能同时在桌上

把这张图和 05 篇的工作台放在一起看，会看到一个很硬的结论：**发散与收敛的差别，不在「第几步」，在「桌上放什么」。**

发散轮的桌子应该是**空的**：只放题材和约束，最好连你上一版写废的段落都撤掉。因为任何一段旧文本都会成为最有力的前缀，它会把十个方向都拉回同一个语气。收敛轮的桌子应该是**满的**：设定簿、上一章、称呼表、伏笔账，一样不能少。因为这一轮要的不是新，是接得上。

同一张桌子上既要「别管旧东西」又要「守住旧东西」，模型只能折中。折中的结果就是你看到的那份稿子：句子像样，人物不像同一个人。

## 27.4 机制一：为什么混在一轮里，产出会平庸

「平庸」不是一个审美判断，它有很具体的成因。三条，都能从 P1 和 P3 推出来。

### 它是在「会被评价」的前缀下续写的

你说「给我 10 个方向，并说明哪个最好」，这句话本身就进入了前缀。于是每一个候选都不是在「什么可能成立」的分布里抽的，而是在「什么容易被论证为好」的分布里抽的。

这两条分布不一样。前者容得下怪东西、半成品、只有一句话的冲动；后者天然偏向**熟悉、完整、好解释**的形状——因为这类形状在语料里最常被写成「好」。结果就是十个方向都体面、都成立、都像某个已经成功过的东西。

这不是它「怕犯错」，也不是它在自我审查。它没有审查这个动作。它只是**在一条已经包含了评判标准的前缀后面，继续往下写**，而那条前缀把概率质量推向了安全区。

### 十个候选，常常是一个候选的十种说法

即使你只说「给我 10 个方向」，不加「哪个最好」，也常常拿到十个近亲：同一个主角、同一种困境、同一个反转位置，只是换了个职业和地点。

原因是抽样的形状。它是在同一个高概率区域的邻域里抽，不是在整张地图上抽。温度能把这个邻域放大一点，但**放大的是同一个邻域**——这一点在 [04 篇](04-sampling-and-reruns.md)说透了：旋钮只改「怎么抽」，不改「有哪些候选」。

所以「多给几个」这句话本身不产生多样性。真正产生多样性的是**条件不同**。你要它给十个方向，就得给十套不同的条件，而不是同一套条件说十遍「再来一个」。

一个可用的做法：把十条约束写成一张表，一条对一个方向。约束可以是受众（给中学生看 / 给夜班司机看）、视角（女主 / 反派 / 一件道具）、结局（和解 / 不和解 / 不交代）、体量（三集 / 一集 / 一个镜头）、禁区（不许死人 / 不许哭 / 不许回忆）。**约束越不重叠，方向越不可能撞车。**

这就是「用约束买多样性，不用温度买」。温度买到的是同一个想法的不同措辞；约束买到的是不同想法。

### 它先写下的评价，会在下一步变成事实

这是混轮最隐蔽的一处伤害。你让它「给 10 个方向，挑最好的写成大纲」，它会先写一句「其中方向 3 最有张力，因为它把冲突放在了……」——然后开始展开方向 3。

问题在于，展开的时候，那句评价已经在前缀里了。它不再是「一个建议」，而是「一个已经成立的判断」。模型不会回头质疑自己上一段写的话，它只会顺着写。于是你拿到的不是「一个被选中的方向」，而是「一个被自我背书的方向」：理由被当成前提，前提被当成事实。

这和 [04 篇](04-sampling-and-reruns.md)讲的「分叉」是同一件事：**第一个岔口选了什么，后面整条路都在替它圆场。** 只不过那里岔的是数字，这里岔的是「这个故事是关于什么的」。

### 发散轮的三条禁令，和一个判据

禁令很短：

1. **不排序。** 不说哪个好、哪个更有张力、哪个更适合你。
2. **不解释。** 每个方向只给三行：一句话冲突、谁最痛、结尾落在哪。不要写「这个方向的好处是」。
3. **不自我评价。** 不写「这个可能有点老套」「这个比较冒险」。这类话会立刻污染后面的候选。

判据也很短：**如果你把十个方向念给同事听，他们能说出「第 3 个和第 7 个是同一类」，这一轮就没发开。** 不是要他们夸好，是要他们能分辨。分辨不了，说明你拿到的是十个措辞。

### 圈 2 个，不是圈 1 个

为什么是两个？因为一个不够对照。

只圈一个，你无法区分「我选了它」和「我被它的推荐语说服了」。留第二个不写，只留着问一句「如果选它，会变成什么样」，你就有了一面镜子：如果第二个听起来明显更弱，说明你的判断有依据；如果两个一样好，说明这一轮的方向还不够分开，应该回去补约束，而不是硬选。

选的时候，判据不是「哪个最好」——「最好」没有判据，它只是一个更顺的说法。判据是：**哪一个你能说出「我想看下去」的理由，而且这个理由不依赖它写的推荐语。** 说不出理由，就先别进收敛轮；进去也是替它打工。

## 27.5 机制二：连续性为什么可以检查

### 不是记性，是账本

「它把上一章的事忘了」是一句很自然的描述，但它会把你引向错误的修法：让它「多记一点」「再强调一遍」。

准确的描述是：**那条决定这一轮不在桌上。** 模型没有跨轮的存储，它这一轮能用的，只有这一次被放进去的东西（P2，见 [05 篇](05-context-workbench.md)）。所以连续性不是它的记忆力问题，是你的**账本有没有被重新放上桌**的问题。这一条在 [11](11-compression.md)、[12](12-memory.md) 两篇已经拆过：压缩会把「待确认」磨成「已确认」，记忆会把「存着」当成「这次会用」；连续性失败是这两件事在创作里的具体形态。

由此得到第一个动作：**连续性必须外置。** 它不能存在对话历史里——历史会被压缩、会被滑出窗口；也不能存在你脑子里——你会记错。它要存在一份可以贴进每一轮的文件里，并且带版本。

### 可检查，与不可判断

创作里有两类判断，混在一起会浪费掉你所有的审稿时间：

| | 连续性 | 好不好 |
| --- | --- | --- |
| 判断方式 | 两条陈述对照，能判「一致 / 不一致」 | 需要读者、语境、品味，常常没有唯一答案 |
| 需要什么 | 一份账本 + 原文 | 一批读者 + 分歧 |
| 十分钟能不能做 | 能 | 通常不能 |
| 谁来做 | 任何人，按表核 | 你，或你信任的编辑 |
| 出错的样子 | 能被指认到具体一句 | 只能说出「不对劲」 |

这个不对称有一个直接后果：**先把审稿预算花在连续性上。** 因为它是这件事里唯一有正确答案的部分，而且便宜。你把怀表是父亲的还是母亲的核清楚，不会让剧本变好；但你留着这个矛盾，后面所有的「好」都会被它拖下水——观众一旦发现前后对不上，就不再相信你设置的任何东西。

### 连续性审稿表

五条线索，五列。这张表可以直接抄，改成你自己的项目名：

| 线索 | 一句话定义 | 具体核什么（可指认） | 断裂的典型样子 | 检查动作 |
| --- | --- | --- | --- | --- |
| **人物动机** | 他想要什么、怕失去什么、绝不会做什么 | 每一场戏里，他追的是哪一个欲望；这个欲望上一场成立吗 | 上一章为钱铤而走险，这一章突然为道义放弃，中间没有一场戏改变他 | 给每个人写一行「他要 / 他怕 / 他不做」，逐场问「这场他在追哪一个」 |
| **时间线** | 事件先后、间隔、季节与光线、谁知道什么 | 字幕与台词里的时间词；白天黑夜；伤口、雨、交通工具的耗时 | 第四场写「三天后」，第七场台词说「上周那事」，指的是同一件事 | 画一条只有日期与事件的线，旁边标「此刻谁知道这件事」 |
| **视角** | 谁在讲，他能看到、听到、推断什么 | 每一段是谁的眼睛；「他心想」的那个人在不在场 | 全篇第三人称限知跟女主，第六场却写男主在另一座城市的独白 | 每段开头标一个视角人；凡写他人内心，回查视角人是否在场 |
| **道具与设定** | 关键物的位置、状态、归属；名字、年龄、称呼、伤口 | 首次出现在哪、移动过几次、最后在哪；称呼从谁开始改 | 上一场丢了的钥匙下一场在口袋里；「周队」忽然变「老周」没人过渡 | 一张道具卡：首次出现 / 每次移动 / 最后状态；一张称呼表 |
| **伏笔回收** | 埋了什么、打算在哪收、收的时候给不给新信息 | 每一条「埋」都要有一行「收」；收的那一栏空着就是欠账 | 结尾的反转靠一句前文从未出现的话 | 两列账：埋（章 / 句）、收（章 / 句）；空着的单独列出来 |

### 三种用法：骨架、diff、回归

**写之前，当骨架。** 先填这张表，再写第一场。填不满，说明你还没想清——这时候写出来的东西，人物动机那一栏一定是空的，而空的那一栏会在第十场以「他突然决定」的形式补上。

**写完，当 diff 表。** 逐条找两处原文，对不上就是断。注意这里要求的是**两处原文**，不是「我觉得不对」。「第四场字幕三天后、第七场台词上周」——这种句子可以直接贴进修改意见，谁都能核。

**返修后，当回归测试。** 你改了一场戏，就把受影响的行重跑一遍。改的是时间，就把时间线与「谁知道」两行重核；改的是称呼，就把称呼表重核。这和 [22 篇](22-evaluation.md)讲评测是同一个道理：一次只改一处，改完只验相关的那几条。

### 虚构示例：三处断裂，三种修法

```text
虚构示例《末班车》的三处断裂（只演示核对动作，不展开故事）

A. 动机：第二场他为还债接活；第五场他为"原则"拒收钱——中间没有一场戏改变他。
B. 时间：第四场字幕"三天后"；第七场台词"上周那事"——指的是同一件事。
C. 视角：全篇第三人称限知跟女主；第六场写了男主在另一座城市的独白。
```

三处都能在一分钟内指认，也都无法用「再润色一下」修好。而且三种修法完全不同：A 要补一场戏（改变必须发生在一个场景里），B 要改一个字幕（或者改那句台词），C 要么删掉那段独白，要么换一个视角人物来承担它。

**这就是「可检查」的价值：它把「读着不对」变成了三种具体的活。** 而「读着不对」本身，是没法派工出去的。

### 最容易犯的错：让它「检查一下连续性」

如果你在对话里补一句「顺便检查一下前后有没有矛盾」，你几乎一定会得到：「已仔细核对，全文前后一致，无矛盾。」

这句话不能作为证据，有三个理由：

1. **它没有对照物。** 它这一轮看见的是当前这段稿子，不是设定簿；要发现「怀表从父亲的变成母亲的」，它得同时看见两处，并且愿意停下来比。前者是 P2 的问题，后者是 P1 的问题——它的默认动作是往下写，不是往回查。
2. **「已核对，无矛盾」是最顺的续写。** 你要求它检查，它就生成一段「检查结果」；而一段合格的检查结果，最常见的形状就是「没有发现问题」。这不是撒谎，是续写。
3. **它会把「没找到」写成「没有」。** 这两件事对下游的影响完全相反，但在文字上长得一模一样（11 篇讲过同一个坑）。

正确的用法是把它当**筛查器**，不当判决者：把表放进这一轮，要求「只列冲突，每条给两处原文，不许给建议，不许说『整体良好』」。然后你核那两处原文。

它仍然会漏——需要世界知识的地方（那个年代有没有这种车、这个城市到那个城市要多久）它未必知道；也仍然会误报——把有意的重复、回环的结构当成矛盾。所以它是第一遍筛，不是最后一句话。**第 4 问的答案永远是原文，不是它的结论。**

## 27.6 「AI 味」：八个可以指认的症状

### 先把定义钉住

「AI 味」是最容易被说成玄学的一个词。常见的两种处理都不对：一种是找「AI 检测器」打分——那测的是另一件事，而且极不稳定；另一种是列一堆形容词（「生硬」「空洞」「没有灵魂」），听完还是不知道改哪一句。

这一篇的定义是：

> **AI 味 = 没有具体观察的写作，取了一个平均的、经过编辑的形状。**

这个定义有两个好处。

第一，它解释了为什么症状那么稳定。模型学的是「这类文字通常长什么样」，而「通常」必然筛掉个别性——留下的就是结构完整、用词得体、每句都成立、但没有一处只有作者才知道的细节。它写的是平均值，平均值当然处处相似。

第二，它解释了为什么这些症状在人类写作里也常见。公文、读后感、学生作文、企业宣传稿，全都有对称排比、形容词堆叠、段末总结。所以「像 AI」更准确的说法是「像没有具体观察的写作」。**这个重新定义很重要，因为它把对策从「去 AI 化」改成了「加观察」——而观察只能你给。**

下面八条，每一条都配一个「一分钟内怎么认」的特征。前七条最常见，最后一条最少被提起。认不出来，就不是约束问题，是还没读进去。

### 症状表

| 症状 | 一分钟内怎么认 | 机制上为什么会出现 | 一条能抑制它的约束 |
| --- | --- | --- | --- |
| **对称句式与三段排比** | 连续三句字数相近、结构相同；「不是……而是……」一篇里出现五次以上；凡列举恰好三条 | 排比是「整齐」的最省力形状，也是段末收束的高频写法；对称句在语料里天然显得完整 | 全文「不是……而是……」最多两次；禁止三项并列，列举要么两项，要么四项以上且长度不齐 |
| **形容词堆叠** | 一个名词前两三个形容词，全是正向且抽象（「深邃而温柔的目光」）；删掉形容词，句子不损失信息 | 形容词是「让句子显得有文采」的最短路径；它不需要知道任何具体的事 | 每个名词最多一个形容词；删掉全部四字成语；「美丽的 / 深深的 / 无尽的」一律删 |
| **每段收束成总结** | 段末是格言、感悟或「这就是……」；把它删掉，段落反而更有力 | 段末是「下一个片段」概率最集中的位置，而一句总结是极高频的收尾 | 每段最后一句只能是动作、对白或一个不解释的物件；禁止以「她明白了 / 他终于懂得」结尾 |
| **元话语** | 「总而言之」「值得注意的是」「换句话说」「让我们」；句子在谈文本本身，不在讲故事 | 说明性文字在语料里大量使用这些路标，它们是最顺的过渡 | 叙事文里禁用「值得注意 / 总而言之 / 不难看出」；说明文每千字最多一次，且必须是真的转折 |
| **过度平衡** | 每个判断后面都跟一句「当然，另一方面」；读完不知道作者站哪；人物没有偏爱 | 被要求「客观」「全面」时，最安全的续写是两头都说；而两头都说等于没有代价 | 每篇必须有一处不做平衡的判断；让步句只留一处，其余删掉 |
| **情绪靠形容词而非动作** | 「她非常悲伤」「他愤怒极了」；情绪由叙述者宣布，不由行为泄出 | 宣布情绪比设计一个能承载情绪的动作便宜得多，而且在语料里更常见 | 禁止「她感到 / 他心里想 / 他非常」；情绪只能通过手部动作、物件位置、对话的省略来写 |
| **对话像在念立场** | 每句话都完整、礼貌、切题；两个人在交换观点，不是在争夺什么；没有打断、没有答非所问、没有说谎 | 对话在语料里常以「被转述的观点」形式出现；而「让读者立刻听懂」是最强的优化方向 | 每场对话至少一次打断或一次答非所问；禁止角色自述动机（「我这么做是因为……」） |
| **细节都对称地有用** | 前面提到的每样东西后面都恰好用上；没有闲笔、没有巧合、没有白出现的人 | 它按「这段文字会被怎样理解」来写，于是每个细节都倾向于「有意义」；而真实生活里大量细节是无用的 | 每章至少留两处不回收的细节；不许让所有道具都变成伏笔 |

### 为什么这八条值得单独记

因为它们全都是**形式特征**，不是内容判断。你不需要先决定「这段写得好不好」，就能指出「这里连续三句排比」「这里段末又总结了」。这让它们可以被派工、被计数、被验收——「删到零个」是可以检查的，「写得高级一点」不是。

再补一句容易漏掉的：**这八条不是等价的。** 最伤的是第三条和第五条。段末总结会让读者养成「跳读」的习惯，因为他知道每段最后一句没有新信息；过度平衡会让整篇失去立场，读者读完不知道该为什么紧张。排比和形容词只是显得油，删掉就干净了；总结腔和平衡腔是结构性的，删掉之后会留下空洞，必须补东西。

### 为什么「逐条删」比「整段重写」有效

重写听起来更彻底，实际更危险，理由和 11 篇讲补丁时一样：

1. **重写会重新抽一次样。** 原来做对的部分不一定还在。你可能为了删掉一句总结，把前面那句本来很好的动作描写也换掉了。
2. **重写会丢掉对照关系。** 你刚标出的那几处症状，是针对这一版标的；整段换掉，标记全废，你又要重标一遍。
3. **重写容易把「改」变成「再生成一次」。** 而再生成一次，很可能带回同一批症状——因为条件没变。

所以正确动作是**定点删改**：标一处、删一处、读一遍、再下一处。改动越小，你越知道是哪一处起了作用。

但这里有一个必须提前说的坑：**减法会让文字变干净，也会让它变薄。** 你把形容词、比喻、总结全删了，剩下的可能是一段干净但空的话。这时候如果你补不上具体观察，文字会从「AI 味」变成「干净的 AI 味」——更难指认，也更难救。删是第一步，补是第二步，而第二步只能你自己来。

## 27.7 约束怎么写：反例比形容词有效

### 判据：第三个人能不能在一分钟内判定

「写得高级一点」不是约束，是愿望。它不可判定，所以模型只能用最常见的方式满足它：更书面、更多形容词、更多四字词、更多比喻。你越说「高级」，它越油。

一条合格的约束要满足三个条件：

1. **可判定**：第三个人读一遍，能说「违反了」或「没违反」，不需要争论。
2. **指到字符串**：能说出具体的词、句式、标点，而不是「语气」「质感」。
3. **有验收动作**：改完可以数一遍、标一遍、对照一遍。

### 空约束与可执行约束

| 你本来会写的 | 它被理解成什么 | 换成 |
| --- | --- | --- |
| 写得高级一点 | 更书面、更多形容词、更多四字词 | 删掉所有四字成语；每个名词最多一个形容词 |
| 更有文学性 | 比喻密度上升，抒情段变多 | 全文比喻不超过三个，且不许用「仿佛 / 宛如 / 像是」开头 |
| 对话自然一点 | 更礼貌、更完整、更切题——正好相反 | 每场对话至少一次打断；不许出现「你说得对，但是」 |
| 节奏快一点 | 句子变短，变成电报体 | 每三百字必须发生一件改变处境的事；删掉所有纯环境描写段 |
| 人物立体一点 | 加「矛盾性格」标签，比如「外表冷漠内心柔软」 | 给每个人写一句「他绝不会做的事」，并让他在本章差点做 |
| 别那么 AI | 一个结论，不是一个动作 | 从上面任选两条具体的，写进约束包 |
| 结尾要有余味 | 加一段抒情和一句格言 | 最后一句不许是总结；把最后一段删掉，看倒数第二段能不能收 |

最后一行值得单独说。**「删掉最后一段」是这篇里最便宜的一个技巧。** 因为模型极擅长写「收尾」，而收尾往往是全篇最平均的一段。你删掉它，剩下的那一段常常正好停在一个更好的位置：一个动作、一句没答完的话、一个没解释的镜头。

### 六条写法

1. **否定式优先。** 「不要什么」比「要什么」清楚，因为「不要」可以被数出来。
2. **一次不超过五条。** 超过五条，约束之间会开始打架，模型会把它们折中成一种四不像；而且你自己也验不过来。
3. **指名到字符串。** 「仿佛」「不是……而是……」「总之」——这些是可以搜的。
4. **一条约束配一个验收动作。** 不是「减少比喻」，是「数一遍，超过三个退回」。
5. **给一条正例锚定语气。** 一段一百字的样本，比十条形容词有效；但样本只锁形式，不锁事实（25 篇）。
6. **同时给一条坏样本。** 只说「照这个写」，它会把样本的缺点一起学走；给一段明确标注「不要这样」的文字，边界才清楚。

### 一个可以直接抄的约束包

```text
本轮约束（可判定，五条，超出请先问）
1 禁词：仿佛、宛如、像是、不禁、深深地、无尽的
2 段落最后一句不许是总结或感悟；只能是动作、对白、物件
3 每个名词最多一个形容词；全文四字成语不超过 3 个
4 对话每场至少一次打断或答非所问；角色不许自述动机
5 比喻全文不超过 3 个，且不许出现在段落开头

验收：改完由第二个人数一遍禁词与比喻数，超过即退回。
```

注意最后一行。**约束如果没有验收动作，它就只是一段更长的愿望。** 这也是全书那句老话在创作里的版本：提示词能提高服从概率，给不出「改到位了」的证据；证据要靠在稿子上数。

### 约束会被适应

同一套约束用久了，会出现一种很典型的现象：它不再犯你禁掉的那一条，但会用另一种方式满足同一个冲动。

你禁了「仿佛」，它开始用「像是」；你把「像是」也禁了，它改用「让人想起」；你禁了「不是……而是……」，它改成「与其说……不如说」。**症状换了一件衣服，功能没变。**

所以约束不是一劳永逸的。你需要一份「新口头禅清单」：每次改完，把这一版里反复出现的三个句式记下来，下一轮加进禁词。这不是在和它斗智，是在维护一份**你自己这个项目的语言卫生**——每个作者都有自己不想沾的腔，把它写下来，比每次现场判断省力。

### 约束会互相打架

另一个常见故障：五条约束里有两条在抢同一个位置。

比如「每段最后一句必须是动作」和「全文不许出现连续两个短句」——一个要求收在动作上，动作句通常短；一个要求句子不能短。它只能折中：写一个又长又像动作的句子，结果两头不靠。

遇到这种情况，不要加第六条去修。**停下来，问哪一条是真需求。** 通常只有一条是你在意的，另一条是你顺手写上的。删掉顺手的那条，文字立刻松。

## 27.8 边界：能做什么、代价、何时失效

| 能做什么 | 代价是什么 | 何时失效 |
| --- | --- | --- |
| 一次给十个方向，且能在不同约束下真的分开 | 十个里有八个不能用；约束要你自己设计 | 需要真正的个人经验时——它没有你的记忆，只能给你「这类故事通常会怎么想」 |
| 按设定簿把一个方向展开成场景 | 设定簿要人维护、要每轮重贴 | 设定簿本身有矛盾，或你忘了更新它 |
| 按连续性表做第一遍筛查，列出冲突与两处原文 | 它会漏（缺世界知识）、会误报（把有意的重复当矛盾） | 冲突落在「没写进表」的东西上：语气、节奏、留白的长度 |
| 用反例约束把文风从「平均」拉回来 | 约束过多会互相打架，文字变僵；减法会让它变薄 | 约束只治表层；治不了「这一场根本没有非写不可的理由」 |
| 补结构：三幕、节拍、章纲、场景目标 | 结构模板会让作品趋同；节拍越标准，越像同类作品 | 主题本身还没定的时候——结构会替你选一个主题 |
| 把一段初稿改成三个不同版本供你挑 | 三个版本常常是同一版的三种措辞；挑久了你会累，然后随便选一个 | 你需要的是「不同」，它给的是「更像」 |

最后一行值得多说一句。**「给我三个版本」是最容易滥用的一个动作。** 它看起来像发散，实际上常常是同一段文字的三次抽样：开头换一下，结尾换一下，中间几乎一样。真正的三个版本要求你给三个不同的条件——比如「一版全用对白」「一版全用动作」「一版从十年后回望」——否则你只是在同一张桌子上抽三次。

### 它能补结构，补不了「你想说什么」

这是本篇最硬的一条边界。

结构是可以外包的：起承转合、三幕八节、每场一个目标一个阻碍、每三分钟一个钩子——这些都有成熟做法，模型学得很好，而且比你快。你把材料给它，它能给你一个「看起来完全成立」的骨架。

但骨架不承载意义。「这个女人最后没有下车」是一个结构选择；「她为什么不下车」才是你想说的东西。前者它可以给你十个方案，后者它只能给你一个**平均答案**——因为「为什么」的答案不在结构里，在你对这个人的理解里。

判断方法很土，但有效：**动笔之前，用一句话写下「这个故事我想说的是____」。可以很土，可以只有六个字。** 写完再看稿子。如果稿子的主题是这句话的一个更漂亮、更完整的版本，那是好事；如果稿子的主题是另一句同样漂亮的话，那你要问一句：是我改主意了，还是它替我改了？

### 作者没想清时，它会替你编一个主题

这一条比上一条危险，因为它的产物更好看。

一篇没有明确主题的稿子，最顺的续写是什么？是那类在语料里被反复写、反复赞过的主题：成长、和解、放下、回家、原谅自己。它会写得完整、动人、前后呼应——甚至比你自己那个还没成型、说不清楚的想法更像一个「作品」。

危险不在它写错。**危险在它写得对，对得让你放弃自己那点还没长好的东西。**

所以这里需要的不是更强的约束，是一次**归属检查**（第 1 问）：这个主题是我想说的，还是它顺着「这类故事该有的主题」写出来的？分辨的方法是两个问题：

- 这个主题，我能不能说出一个只有我知道的具体场景？说不出，多半是它给的。
- 如果把这句主题拿掉，那些戏还成立吗？如果立刻散架，说明戏是为主题凑的，不是从戏里长出来的。

### 三个该停下的信号

1. **你说不出这一场戏里「谁想要什么」。** 这时候继续写，写出来的每一场都会是对的，也都会是可以删的。
2. **你连续三次让它「再深一点」，每次更顺。** 更顺通常意味着更平均。深不深，不看你读的时候有没有被感动，看你读完之后有没有想到一个具体的人。
3. **你开始替它的设定辩护**（「这样也说得通」「观众不会注意」）。这是最危险的一个。你在替一个不是你做的决定找理由，而且找得越来越熟练。

### 素材不是默认可用的

还有一条不属于机制，但必须在这里说：**你让它参考的东西，不等于你拥有它。**

- 你说「参考某某剧的风格」，它给你的不是那部剧的授权；风格与表达的边界要单独判断。
- 你说「照这张照片写人物」，写出来的脸仍然涉及肖像；换成文字不改变来源。
- 你说「配一段类似的音乐」，音乐不会因为描述得像就变成你的；文字生成不了授权。
- 再往上一层：这个工具的训练素材从哪来、生成的东西能不能商用，不是模型能回答的问题。它对自己的训练数据没有可靠的账本，它的说法也不能当授权依据。

这三件事都不在模型的能力范围内，也不在提示词的范围内。核法见第 29、31 篇。

### 这个类比在这里失效：「AI 是实习生」

「把它当实习生带」是最好用的一个类比：给任务、给参考、给反馈、逐步放权。它在大部分场景成立，在这一步失效：

**实习生的不确定是可见的，模型的不确定是不可见的。**

实习生会停下来问「这里我不确定，这个人是左撇子吗」；模型不会。它会在空白处填一个最顺的东西，而且不标注那是填的。你收到的是完整的稿子，不是「已完成 80%，20% 靠猜」的稿子。

所以带实习生的方式在这里要改一处：**你不能靠「他没问就说明他会了」来判断，你得给他账本，然后自己核。** 信任的替代品不是更多的信任，是更细的对照。

## 27.9 反例与正例：同一段的两次返修

虚构示例，只为演示诊断与修改，不代表任何真实作品。

**初稿（带 AI 味）：**

> 她的心中充满了无尽的悲伤，仿佛整个世界都在这一刻崩塌了。她明白，人生就是一场不断告别的旅程，而我们能做的，只有学会放下。

**诊断。** 两句话，踩了四条：

| 句子 | 症状 | 具体在哪 |
| --- | --- | --- |
| 「充满了无尽的悲伤」 | 情绪靠形容词 | 「悲伤」被宣布，读者没有看到任何承载它的动作 |
| 「仿佛整个世界都在这一刻崩塌」 | 空泛比喻 | 「仿佛」开头；「整个世界崩塌」是最平均的一个比喻，读不出任何具体的东西 |
| 「她明白，人生就是……」 | 段末总结 | 从具体场景跳到人生格言，句子在替读者总结 |
| 「我们能做的，只有学会放下」 | 过度平衡 + 元话语 | 「我们」把叙述者拉进来讲道理；「只有」是一种伪装的确定 |

**错误的修法：**「写得更文学一点，更有感染力」。结果一定是加更多比喻、更多抒情、更长的排比——因为那是「文学」在语料里最常见的形状。

**正确的修法：**先给约束，再补观察。

约束（三条，够用）：删掉所有「仿佛」开头的比喻；不许写「她感到 / 她明白」；情绪只能通过她对手边物体的动作体现。

补观察（这一条只能由作者给）：她此刻在做什么？在收拾碗筷。她给谁收的？一个不会回来的人。

**改后（同样虚构）：**

> 她把两副碗筷摆上桌，又收回去一副。锅里的水开了，她没关火。

**这不是「更好的文学」，它是另一种选择。** 差别是可指认的：情绪从形容词挪到了动作（摆、收、没关火），总结被删掉，留下一个不解释的细节（水开了不关）。好不好仍然要你判断——但它至少是可以讨论的：你能说出改了什么、为什么改，别人也能说出不同意在哪。

整条链摆在一起看，两种返修的区别一眼可见：

```text
错的链：看着不错 ──▶ "再润色一下，更深刻" ──▶ 句子更顺 ──▶ 矛盾还在 ──▶ 再润色
                                                              （循环，且每次掉一格设定）

对的链：看着不错 ──▶ 先分两堆
                        ├─ "像平均" ──▶ 症状表里标三处 ──▶ 定点删改 ──▶ 补具体观察
                        └─ "对不上" ──▶ 五条线索逐条查 ──▶ 补一场戏 / 改一个字幕 / 换视角
```

**注意一件事：这段改后文字不能当模板批量套。** 如果你把「极简动作 + 不解释的细节」当成新的公式，用到每一场上，你会得到一种新的平均——极简腔。它比原来的抒情腔更难被指认，因为它看起来「克制」。**反 AI 味也会形成新的 AI 味**，这是这一节最需要记住的一句。

所以每次改完，问一句：**我是在解决这一处的问题，还是在执行一个风格？** 前者会停，后者会蔓延。

## 27.10 检验：十分钟，三处标记与三条约束

这个检验不需要任何工具，一段三百到五百字的稿子就够。用你自己写的也行——人写的稿子同样会有这些症状，这正好能证明它们不是「机器指纹」。

**做法：**

1. 取一段初稿，读完一遍，什么都不改。
2. 用 27.6 的表标三处。每处写两样：症状名，以及那半句原文（必须抄原句，不许写「大概在第三段」）。
3. 每处写一条约束，按 27.7 的三个条件自查：可判定、指到字符串、有验收动作。
4. 只改这三处，别的一个字不动。改完读一遍。
5. 找一个人，不告诉他你改了哪里，让他读两版，指出哪一版更想读下去，并说理由。
6. 记下他的理由。如果理由全是形容词（「更高级」「更有感觉」），这次修改没有被验证；如果他能指到具体那一句，把那一句记下来。

**记录表：**

| 固定什么 | 只改什么 | 观察什么 | 什么结果会推翻文中结论 |
| --- | --- | --- | --- |
| 同一段原文、同一批约束 | 三处定点删改 | 读者能否指到具体那一句 | 读者说不出差别，或差别全在「更短」上 |
| 同一段原文 | 一次只改一处 | 三处里哪一处真正影响阅读 | 三处各自都不影响，说明症状表在这个文体上不适用 |
| 同一套约束 | 连续用三次 | 是否出现新的口头禅（「像是」「与其说」） | 三次之后症状不减，说明约束没进这一轮 |

最后一行是反向检验，值得单独做：**故意把一处 AI 味加回去，看对方察不察觉。** 察觉不到，说明在你这个文体、这个读者身上，这条症状不承重——那也是一条有用的信息，比你以为的「我删对了」更可靠。

## 27.11 术语考古：文风、元话语、连续性

三个词都被用得很松。四栏填完，很多争论会自己消失。没有可靠出处的，标「社区用语」，不编年份。

### 文风

| 栏 | 内容 |
| --- | --- |
| 最早出处 | 汉语写作与文体研究里的通行概念（「文体」「风格」），指作者在语言选择上表现出的稳定特征。**没有单一发明人，也没有统一规范定义，不编年份。** |
| 原义 | 由一组具体选择构成：句长、词的层级、比喻密度、视角、段落怎么收。可描述、可比较、可模仿。 |
| 现在被怎么用 | 常被压缩成一个形容词写进提示词（「高级」「有质感」「像某某作家」），或被当成检测器能打分的属性。 |
| 本文怎么用 | 一组可指认、可计数、可对照的选择。写约束时必须落到这一层；只给形容词，等于没给约束。 |

### 元话语

| 栏 | 内容 |
| --- | --- |
| 最早出处 | 语言学与写作研究中的通行术语（metadiscourse），指用于组织篇章、引导读者、表达作者态度的那一部分语言。**具体最早文献本文不指定，不编年份。** |
| 原义 | 「关于话语的话语」：不讲事情本身，而讲「我接下来怎么讲」「你怎么读我这段话」。 |
| 现在被怎么用 | 被当成「AI 腔」的同义词，凡是不顺眼的连接词、过渡句都叫元话语。 |
| 本文怎么用 | 只指指向文本自身或读者关系的句子（「总而言之」「值得注意的是」「让我们来看」）。它在说明文里可能是路标，在叙事文里通常是噪音——判断标准是文体，不是词本身。 |

最后一句要展开一点，因为它是本篇最容易被误用的一条。**元话语不是坏东西。** 这篇正文里就有大量「这一节要说明的是」「先把定义钉住」——它们在帮你定位。问题只出在叙事文里：小说里出现「值得注意的是」，等于叙述者突然从故事里探出头来跟读者开会，那一刻虚构就破了。所以约束要写成「叙事文里禁用」，而不是「全文禁用」；写成后者，你会在写说明文的时候被自己的规则绊倒。

### 连续性

| 栏 | 内容 |
| --- | --- |
| 最早出处 | 影视与出版行业里的场记、剧本统筹工作（英文 continuity 常指「连戏」）。**作为岗位与流程属行业实践，没有单一发明人，属行业与社区通行语。** |
| 原义 | 让相邻镜头、相邻章节在服装、道具、时间、位置、称谓上接得上；谁在什么时间知道了什么，也要接得上。 |
| 现在被怎么用 | 常被说成「AI 的记忆力」，仿佛它是模型的一个能力；于是修法变成「让它多记一点」。 |
| 本文怎么用 | 一组可逐条比对的承诺（动机、时间、视角、道具、伏笔），靠外部账本维护。**不是记性，是核对。** |

三个词放在一起，能看出一条共同的误读路径：**把一个需要外部标准的东西，说成了模型的一个属性。** 文风被说成「质感」，元话语被说成「AI 腔」，连续性被说成「记性」。三个说法都让你把活派给了模型，而这三件活本来都在你手上：选哪些选择、判断哪种文体、维护哪本账。

## 27.12 一页速记

| 你遇到的情况 | 一句话带走 |
| --- | --- |
| 十个方向都差不多 | 不是它没创意，是条件没变；用约束买多样性，不用温度买 |
| 它一边给方向一边排序 | 删掉排序与推荐；候选在「会被评价」的前缀下一定趋同 |
| 前后对不上 | 不是它忘了，是那条决定这一轮不在桌上；把账本重贴一遍 |
| 它说「已核对，无矛盾」 | 这是自述，不是证据；要它给两处原文，然后你核 |
| 读三段就想跳 | 先数段末总结与排比，不用先判断好坏 |
| 改了更像 AI | 你在给形容词，不在给反例；换成可判定的禁词与句式 |
| 删完变干了 | 减法只解决「不要什么」；补具体观察，而观察只能你给 |
| 主题很完整，但不像我的 | 它替你选了一个平均主题；回到「我想说的是____」这一句 |

**五句话带走**

1. 发散与收敛是两种输入，不是两个步骤；同一张桌子上既要「别管旧的」又要「守住旧的」，只能折中出平庸。
2. 十个候选常常是一个候选的十种说法；多样性来自条件差异，不来自温度，也不来自「再来一个」。
3. 连续性是可检查的：动机、时间、视角、道具、伏笔，五条线索，每条都要能找到两处原文。
4. 「AI 味」不是机器指纹，是没有具体观察的写作取了一个平均形状；每一条症状都能在一分钟内指认。
5. 约束要可判定、指到字符串、有验收动作；「写得高级一点」不是约束，是愿望。

**最后一句**：这篇不要求你记住这八条症状。它要求你在下一次拿到一份「看着不错」的稿子时，先做两个动作——**把它拆成「哪几句像平均」和「哪几处对不上」两堆**，然后只处理这两堆。前者靠约束，后者靠账本；两件都不在句子里，也都不在它的能力里。

**三道自检**

1. 「先给我 10 个方向，挑最好的一个写成大纲」——这句话的问题在哪？如果你的时间只够跑一轮，你会砍掉哪一半，为什么？
2. 它说「我已核对过，全文没有前后矛盾」。这句话能当作连续性的证据吗？你需要它交出什么，才可能变成证据？
3. 你把「写得高级一点」改成「删掉所有四字成语」，改完文字确实不油了，但读起来发干。这是约束失败了吗？下一步该做什么？

<summary>查看参考答案</summary>

1. 问题在把发散与收敛压进同一轮。前半句让候选在「会被排序」的前缀下生成，十个方向会趋向安全、熟悉、好解释的形状；后半句让它先写评价，而那句评价在展开时会变成既定前提，被当成事实继续写下去。如果只能跑一轮，砍掉「排序与推荐」，保留「十个方向 + 你自己圈」；**不能砍的是约束差异**——十条约束如果一样，十个方向就是一个方向的十种说法，砍了排序也救不回来。理由：多样性来自条件不同，不来自温度；温度只放大同一个邻域。

2. 不能。它这一轮没有对照物（设定簿不在桌上），而「已核对、无矛盾」是要求它检查时最顺的一句续写；这是自述，不是回执（第 3、4 问）。要它交出三样东西才可能变成证据：每条冲突的两处原文（章 / 句），这次核了哪几条线索（范围），以及「未发现冲突」是否等于「没有找」。然后你核那两处原文——验证物永远是原文，不是它的结论。

3. 不算失败，算只做了一半。减法让文字变干净，也会让它变薄：约束解决的是「不要什么」，解决不了「要什么」。下一步不是把约束撤掉，也不是加更多形容词，而是补具体观察——一个只有你知道的动作、物件或一句对话。如果补不出来，说明这一场你还没想清；这时候该回到「我想说的是什么」，而不是继续调约束。
