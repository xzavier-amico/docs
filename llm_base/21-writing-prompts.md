# 21 · 提示词怎么写：目标、材料、边界、格式、验收

> **状态**：已完成（初稿）
>
> **本篇定位**：Part V · 真的交付。把一句「帮我弄一下」改成别人也能接手、做完也能核对的任务。
>
> **读法**：先看市集的正反例；赶时间就复制任务卡，填完再用文末练习检查一遍。

你说：「帮我整理下周末市集，写个通知。」AI 很快回了一封热情的邮件：「周六见！如果下雨，我们就在室内见。」句子没毛病，两条事实都不能交付：现行通知已经改成**周日 14:00**，雨天是否改室内仍**待确认**。更糟的是，如果应用正好有发信权限，「写个通知」究竟是起草，还是连同发送一起做？

本篇只回答一个问题：**怎样让模型知道什么叫「做好了」？** 不是把提示词写得像合同，而是把本来只在你脑子里的判断写出来。开始前想一想：你拿到结果时会先看哪里？你看到哪一条就会立即退回？这些往往才是提示词里最值钱的话。

```text
你写任务卡                 模型按卡做草稿            你接手做验收
目标、材料、边界     ──→   结果、依据、未决项   ──→  对材料、看缺项、决定是否接收
格式、验收条件             关键资料缺失则提问          若需外部行动，另行授权
```

## 1. 同一件事，五句话各管什么

假设你手上有原通知 v1（周六，已失效）、主办方现行通知 v2（周日 14:00，雨天是否改室内待确认），还有三条虚构报名记录：R01 纸舟书摊，字段齐全；R02 风铃工作室，缺摊位类别；R03 纸舟书摊，与 R01 同名但未核实是否重复。只整理清单和通知草稿，不发送，也不改原表。

| 任务卡字段 | 写进去的话 | 省略它容易发生什么 |
| --- | --- | --- |
| 目标 | 给主办方一份可审阅的三条报名清单和一份摊主通知草稿 | 写出长篇活动方案，却没有可以核对的名单 |
| 材料 | 时间以现行 v2 为准；v1 只用于解释改期，不当当前依据；名单只用报名原表 | 把提到次数较多的周六当成现行安排 |
| 边界 | 不发送、不发布、不改原表；不猜缺项、不擅自合并同名记录 | 「为了帮忙」自行改数据，或向外承诺未定安排 |
| 格式 | 清单逐条列报名编号、摊位名、核对备注；另附草稿和待确认项 | 重要缺项被埋在段落里，人工审阅费时 |
| 验收 | 三个编号齐全；时间为周日 14:00；天气安排不作承诺；稿件明确标为待审未发送 | 看起来像完成，但不知道哪些错误足以退回 |

格式和验收不是一回事。格式是「给我一张表」；验收是「三个来源编号各有一行，缺项没有用猜的补上」。目标和边界也不是一回事：你可以要一份可供发送的通知草稿，同时禁止本次发送。对带工具的应用，提示词负责表达意图，真正的禁发还应由人或应用控制权限，不能只信模型读到了那句禁令。

## 2. 从差提示词到可查的结果

| 差提示词 | 较好的提示词 | 仍需人工核实 |
| --- | --- | --- |
| 「把纪要总结一下。」 | 「只按这份纪要，分列已决定、备选、未决；责任人和期限没写就标未注明。」 | 回看原段，确认没把『建议改室内』摘成既定决定；责任人是否只是发言者？ |
| 「市集到底哪天？直接给答案。」 | 「只依据主办方现行通知回答时间，标出处；把旧版及未决安排另列，现行依据缺失就停问。」 | v2 是否真的获主办方确认？原句是否真的支持结论，而非只提到同一个日期？ |
| 「把文件和表格都整理干净。」 | 「只据给定文件和原表做一份整理建议，逐项标注现行、旧版、待查；不要移动文件、改表或合并同名项。」 | 是否每条原记录都能追溯，是否把『疑似重复』当成了删除许可？ |
| 「想几个有创意的通知。」 | 「给三种开头：直接、温和、俏皮。只变写法，不变时间、不编场地、不加入催缴或报名截止。」 | 三个版本是否真的好懂？有没有顺手写出未经批准的新承诺？ |

同一句「不要猜」能做的事有限。先告诉模型怎么区分「定了」和「没定」，再给它在缺信息时的下一个动作。比如场地没定，但可以写「雨天安排待确认」，不必把整份任务卡在门口；现行通知根本没给，则不能依据失效版本填写日期，应该先问或暂留空。把两种情况写清，能减少模型乱猜，也省去大量没有必要的追问。

## 3. 哪些不能变，哪些可以让模型决定

| 类别 | 市集里的判断 | 可以这样写 |
| --- | --- | --- |
| 必须满足 | v2 权威、禁发、原表不改、时间和雨天状态不变 | 「如不能满足，说明原因，不用其他安排替代。」 |
| 可采用默认 | 按编号排序；用简洁、中性、对摊主友好的语气 | 「没有特别说明时用这些默认；只改表现，不改事实。」 |
| 需要先澄清 | 缺现行通知、两份都自称现行而无权威可判、用户又要求立即给确定安排 | 「指出冲突，问谁能确认；同时交付不受影响的部分。」 |

不是所有空白都值得先问。排序改错，下次拖一下就好，适合默认；把旧版当新版，对外发错通知，纠正成本高，要核对或停下。相反，明确标成「待确认」的雨天安排本来就是资料里的事实，必须保留这个状态，不必为了填满草稿反复追问。你可以请模型列三种可能，但必须把「候选方案」和「已经定了」放在不同位置。

### 给示例是为了学格式，不是为了学事实

> 格式示例（下列内容均为虚构占位，不是本次资料）：「示例摊位｜示例编号｜缺类别｜来源：示例表」。请沿用列与顺序，实际值只从本次材料提取。

不要在格式示例里写「周六 10:00」然后指望一句「请参考」会被读成只参考排版。最好让示例一眼看出不是这次的数据。如果示例与有效资料冲突，材料决定事实，示例只决定样式。即使答案给出一个出处，也要打开具体位置检查原文；出处名称正确，不代表前面的结论正确。

## 4. 一张可以直接复制的任务卡

> 我要给主办方审阅一份周末市集报名清单和一份摊主通知草稿。按我附的报名原表和两版通知工作。主办方现行 v2 是日期、时间和安排的依据，周日 14:00；雨天是否改室内尚未确认。v1 原定周六，已失效，只可解释发生了改期。若附件与你收到的版本说明冲突，先指出冲突，不替主办方裁决。
>
> 只整理和起草。不发送、不发布、不改原表，不补猜缺项，不自行合并同名记录，也不要把报名等同于已确认获得摊位。
>
> 先交清单，每条写编号、摊位名、核对备注和原表出处，默认按编号排。从通知另起一段，写一个标题和一段短正文，标明「草稿·待审·未发送」。最后列待确认事项、需要谁确认；如只缺局部资料，先交不受影响的部分。
>
> 交稿前逐项核对：原表记录无遗漏，缺项与疑似重复可见；通知时间是周日 14:00，雨天安排仍待确认；没有未经确认的安排或外部动作。能核对的写依据，核对不了的标明。请等我审稿；本次没有发送授权。

用在别的任务上，只需逐项替换。想写更短，也可以复制下面这一版：

> 我需要交给【审阅人】一份【产物】，用于【用途】。请依据【材料和版本】，按【依据优先顺序】处理冲突。必须做到【关键要求】；只可做【范围】，不得做【禁止动作】。【格式或例子】只示范形状，不提供事实。【低风险缺项】可按【默认】处理；遇到【阻塞条件】，请先问，并交出不受影响的部分。交付后用【逐条验收条件】自查，列依据和未决项，不要声称做了无法证明的事。

一份通过纸面初审的输出，可能只需要下面这些。这个版本不声称已经实际联系摊主或完成发信：

| 编号 | 摊位 | 核对备注与依据 |
| --- | --- | --- |
| R01 | 纸舟书摊 | 字段齐全；与 R03 同名，待核；报名原表 R01 |
| R02 | 风铃工作室 | 缺摊位类别；报名原表 R02 |
| R03 | 纸舟书摊 | 与 R01 同名，待核；报名原表 R03 |

> **草稿·待审·未发送：市集时间调整**
>
> 各位摊主好，市集调整至周日 14:00。雨天是否改室内尚未确认。
>
> **内部审阅备注（不入正文）：** 时间及雨天状态依据现行 v2。请主办方核对 R02 摊位类别、确认 R01 与 R03 是否重复，并确认雨天安排。

这样的表也只说明你在给定材料里核对了什么。字段齐全不代表报名有效，昵称相同不代表同一个人。让模型先自检可以发现漏列和不一致，但它也可能重复自己的错误；对外行动前，最好由见得到原件的人再查一次。

## 5. 手工练习：拿走一张材料，再看会出什么错

1. 把「帮我整理市集」写在纸左边，右边填五个格：目标、材料、边界、格式、验收。
2. 把日期和雨天安排圈起来，假装拿走 v2。写出草稿和清单应分别怎么处理：日期不能发布为确定事实；名单仍能按原表整理，通知可先留待确认或只交模板。
3. 请同伴扮演接手者，只看你的任务卡。若他问「我能删同名项吗」「现在要发吗」，检查是你的边界没写清，还是动作本来就不应开放。再用一张故意把 R03 删掉的表，试试验收条件能否直接退回它。

**边界：** 提示词能减少猜测，不能补上没给的权限、资料或实际执行证据。错误若出在应用用了旧资料，把说明再写长也不会让模型自动看见正确版本；错误若出在应用可以擅自发送，则先关发送权限。简单任务也不必铺满长模板：一句话能说明清楚产物、来源和不做什么，就用一句话。

**速记：** 目标决定交什么，材料决定能说什么，边界决定能做什么，格式让人查得动，验收让人知道该不该收。

### 自检

1. **示例里写周六，现行通知写周日 14:00，听谁的？** 简答：事实听现行 v2，示例只管格式；旧 v1 不能支持当前日期。
2. **雨天安排待确认，是否必须停止整个任务？** 简答：不必；照常整理名单，草稿照实标未决，不替主办方宣布进室内。
3. **草稿格式漂亮，为什么还要对原件？** 简答：格式不证明记录齐全或事实正确，模型自检也不等于独立核对。
